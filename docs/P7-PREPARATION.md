# P7 八类部件开发准备

2026-10-04。用户授权“按推荐方案继续，不要询问”，在既有八类机械部件范围内采用以下初版。P6仍先完成验收与冻结，随后升为dev.12；不能把本准备记录写成部件已经实现。无新生产依赖，无真实用户存档迁移。

## 推荐规则

- 翼：被动滑翔面，必须有水平速度才降低下降，不凭空悬停；原版重力、碰撞和有限载重仍保留。风扇可提供前进，翼本身不耗电。
- 火箭：独立一次性有限燃料，首次启用后连续燃烧完，不可通过关机、拆装或重载回满。保存剩余燃料；用尽可回收空壳作材料，不在充电器充燃料，不增加新的矿石体系。
- 弹簧：实际接地并启用时一次弹射，消耗整笔电量，原版碰撞决定能否移动。离地不重复触发；必须关机、落地、冷却完成才可再次触发，保存剩余冷却，不通过卸载计算离线倒计时。
- 轮子：只在实际接地时供前后驱动，原版乘客W/S控制，A/D转向；地面检测使用原版碰撞，简单一格坡面采用受限台阶探测。离地不产生驱动力，满供电不足时不扣部分费用。
- 稳定器：有限抑制横向漂移，释放方向键后减少转向残留；展示姿态保持平稳。不提供无条件悬空或完全抗撞。碰撞仍是固定主体盒，不引入复杂刚体系统。
- 浮力装置：首版以水为作用介质，被动浮起到水面，有载重上限；空气和岩浆不起作用，不额外耗电。用于渡水，翼负责滑翔；空气浮升可在风/天气阶段单独评估。

六个稳定节点继续沿用编号和完整物品保存；同一主体最多一个电池，部件安装、创造模式转移、所有权、空手拆卸、库存容量、启停、回收与网络边界沿用P6。每个节点只装一个部件；不能自由抓取方块或任意粘贴机械。

## 实施顺序与验收

1. 先制定P7-SPEC的能耗、载重、触发和保存参数。增加六件部件及原创原型图标/实体外观、生存配方和中英文说明；扩展节点种类视图，不同步完整堆栈。
2. 实现翼与轮子，实际客户端完成地面驾驶、离地失驱和有限滑翔；测试墙、台阶和耗电。
3. 实现火箭与弹簧，验证一次性燃料、整笔弹射、关机/拆装/重载不会重置已用资源；回收空壳和剩余燃料有明确说明。
4. 实现稳定器与水中浮力，验证有/无载重、岸边、水面、空气、岩浆，禁止无成本空气浮升。
5. 验证六类独立行为及与风扇/电池的组合：耗电上限、碰撞、乘客、节点旋转、区块和真实存档重载。保留P6六节点和旧电池格式1读取，不改旧玩家附件。
6. 运行完整服务端、专项实际客户端和独立服务端验证，冻结dev.12完整阶段及交接；只有六类都通过才标记P7完成。继续P8制造机，额度任一有效窗口剩余≤5%时先保存检查点并停止，不使用重置额度。
