# C6F：连续玩家骨架的真实盾兼容

接续本机dev.29/4ee76a3，2026-10-12；不新增战斗规则、生产依赖、存档数据或公开发布。

## 本批选择

主手为剑、真实副手盾、无盔甲/披风、地面静止时，实际锁定且实际使用副手盾才选择已采用shield-guard/v01的raise/hold/lower左右剪辑。纯锁定持盾未使用时保留原生携盾；非锁定举盾、举盾移动、主手盾、其他武器、空中与复杂状态保持原有路径。普通剑出手且持盾时使用sword-regular/v02的shield_A左右剪辑，依权威阶段归一化映射0.65–2.05秒；不会增加攻击或允许攻击期间格挡。

locked-idle/v02的shield_R/L是持盾准备站姿，其盾面大部分向侧面，不能当实际防御姿势使用。本批采用shield-guard的0.18秒raise/lower与2.5秒hold；转换到共同22蒙皮骨＋6握点，12实际皮肤网格保持。源文件有混合来源链，仅本机派生资源，不作为独立动作素材公开。

## 原生物品与规则

盾沿左右shield_mount提交真实ItemStackRenderState，与剑一样只提交一次，不生成参考盾，不复制库存。原生盾板为12×22像素，板z=-2..-1、握把z=-1..5像素；共用原生边界中心z=.09375方块，对照原源稿的居中全尺寸参考，不缩放模型。用当前原生层变换解出轴向/中心，再匹配源挂点，保留原生SpecialRenderer、染色/旗帜、glint与Fuse附着层。

实际使用、盾判定、普通格挡延迟/耐久、完美格挡与原生伤害继续由现有代码负责。完美格挡8刻程序脉冲仍优先，暂不把本批持盾循环冒称完美格挡源稿。手上换物、GUI、受击、武器蓄力、取收与探索优先。

暂停时现有输入系统会先结束举盾并可能清掉锁定。本批不能为了保留一段动画而改回这个行为；仍合法的同剪辑时钟冻结，实际角色被取消时允许raise/hold/lower换段或回原生。检查须允许这种合法状态变化，不能要求已经退出的hold一直播放。
