2026-10-07，C6A / dev.24。原始设计32项完整列入[可编辑CSV](CORE-ANIMATIONS.csv)，现有源代码引用只代表可修改的程序姿态，不代表Blender/Blockbench完整动画源稿。现有探索参数源为[character-poses.json](../../src/client/resources/assets/wildcraft/animations/character-poses.json)，可对照CSV中的运行类阅读；冻结的原始交付继续保留。采用台账仍43项；既有CharacterPoses参数是已采用材料，不能将新清单批量登记为已采用。

按表的触发与退出制作，客户端消费权威状态；动画不能决定伤害时间、给予无敌或锁住普通受伤后的玩家输入。头部保留准星瞄准，躯干与四肢用局部遮罩。探索攀爬/滑翔和真实物品使用优先；盾手与主手从真实使用手提取，左右镜像不交换库存。标准/纤细分别预览，原生袖子/裤腿是子节点，盔甲消费一次同一遮罩。披风/鞘翅场景验背负侧腰布局。

制作顺序：锁定步态与剑斧/盾/闪避 → 空中与三叉戟/重锤 → 攀爬/滑翔/弓 → 取收装备身体剪辑 → 驾驶与环境。CSV中“循环”和时间是当前运行合同；缺失动作的时长只是制作建议，不引入运行规则。攀爬按距离步进，不导出为固定世界刻循环；进入混合0.12实际秒，开伞0.3秒，离开0.2秒，暂停停止实际过渡。弓/闪避林克时间期间，玩家身体不因世界降到5TPS拖慢实际时间技能。驾驶不混进32项原清单，另需坐姿/站姿、加减速与火箭反馈合同。

交付每项：可编辑源文件、导出文件与工具版本、人体标准/纤细骨骼映射、默认右手及左手镜像、部位遮罩、循环边界、第一/第三人称预览、四槽盔甲/披风/鞘翅/背负验收图。源稿建议一项一个目录并按版本归档，源工具由真实交付选择，不为未制作素材增加运行依赖。新稿验收后再更新采用台账，禁止覆盖冻结历史源稿。

C6A额外程序动作：三叉戟准备/突刺、重锤双臂准备/出手；参数与边界见[C6A合同](../C6A-SPEC.md)。这些是可运行的基础叠加，第一人称仍为主手有界变换，完整双手握持与取收身体剪辑待正式源稿接入。重击硬直玩家动作尚未实现，不能用C4敌方硬直充数。
