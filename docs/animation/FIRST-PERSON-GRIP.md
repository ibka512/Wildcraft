# 第一人称握持接手说明 / C6C

本批为程序握持基础，沿真实权威动作时机渲染原生皮肤手臂，未生成或采用新的32项动画剪辑。规格与实际证据见 ../C6C-SPEC.md、../C6C-VERIFICATION.md。原来主手相对摄像机的有界变换，现改为在原生武器提交位置以真实握柄为轴变换；手臂与武器/融合材料共用最终矩阵。

| 场景 | 主手 | 副手 |
| --- | --- | --- |
| 剑准备/攻击 | 单手握持 | 原生物品或空手 |
| 斧准备/强击 | 握持 | 空闲时支撑；轻击出手单手 |
| 三叉戟/长矛/重锤准备/攻击 | 握持 | 空闲时支撑 |
| 真实副手有盾/火把等 | 握持 | 继续原生物品，不借用也不收起 |
| 使用/瞄准镜/激流/旁观者 | 原版路径 | 原版路径 |
| 不可见玩家 | 皮肤臂不渲染，物品由原版决定 | 同左 |
| 恢复结束或互斥取消 | 原版路径 | 原版路径 |

MeleeHands使用独立标准/纤细PlayerModel，原生skin body纹理和左右袖子设置；不修改共享第三人称模型、存档或装备身份。第三人称MeleePoses长柄/重锤只在另一手空闲时覆盖支撑臂，否则原生持物姿态保持。原版头部/四槽盔甲等沿旧回归，不由第一人称皮肤臂拥有。

握柄点以原版模型局部坐标定义：剑/斧/重锤普通sprite使用主(.23,.23,.5)、支撑(.35,.35,.5)；长矛手持32像素sprite使用主(.70,.30,.5)、支撑(.53,.47,.5)；立体三叉戟主(0,1.10,0)、支撑(0,.70,0)。读取原生首层ItemTransform并应用左右手修正，再合成其localTransform，把这些点变到同一个原生手持根矩阵；三叉戟不能用普通sprite点代替。没有复制游戏贴图或模型源代码。替换资源包可改变握柄形状，未声称所有第三方资源包已经适配。

程序准备/出手以当前权威世界刻年龄计算，不新建动画驱动伤害事件。第一人称把握柄移到视野下方侧面、整体比例0.85，以握柄为轴旋转，保留原生挥动/装备高度；肤臂掌心落在同一握点，按主手方向从视野下方延伸。首个候选在摄像机原点旋转，使部分手臂出屏，虽逻辑测试通过仍被视觉检查淘汰；最终以握点定位并重新跑完整回归。

后续优先制作/接入核心32项真正可编辑动作源稿、独立取收剪辑，并补长柄与重锤的完整准备/出手表现。此处的基础握持不是最终动画或长期人工手感验收，不借新增资产台账夸大完成度。驾驶、环境动作、设备设置与实际硬件、C7单人生存与战斗平衡仍待后续。
