# Wildcraft dev62 单人试玩指南

本机版本：0.1.0-dev.62，Minecraft Java 26.3。使用 Fabric Loader 0.19.5、Fabric API 0.161.0+26.3，Java 25。当前优先单人模式。

试玩包里的游戏文件与已验收的dev62安装包完全相同。本轮已补充组合保存/退出检查：三组自动检查59秒、22张实际画面；此前角色与原生回退的48组完整检查51分6秒、2021张实际画面。自动检查不代替正常生存的获取成本、自然地形操作和长期性能记录。

## 安装与开始

使用单独的Minecraft 26.3 Fabric游戏目录，把本包mods内的Wildcraft JAR与已附的同版Fabric API一起放入该目录mods。包内的Fabric API是现有已使用的0.161.0+26.3依赖原件，没有新增或升级依赖；保留其原LICENSE。包内没有代安装Fabric Loader或包含游戏程序/账号文件。开发工具链与原有环境不需要升级。

新建普通单人生存世界。用新的世界进行试玩，先保留原有存档备份，不拿旧的长期世界进行试验。人工试玩从正常采集和合成开始；需要另外测试某个动作时可以另建提供物品的世界，但要单独记录。

这份包只供本机使用，包含当前许可受限的玩家动画派生数据，没有上传或公开发行。正式第一人称源、披风/复杂形态和长期平衡仍待完成；没有把原生回退当成新动画已经支持。

## 主要操作

| 操作 | 默认输入与要求 |
| --- | --- |
| 背包与装备 | E打开背包；把伞放进独立滑翔伞装备位 |
| 攀爬 | 贴墙按住G；方向键移动，松开G放手；攀爬消耗精力 |
| 开伞与收伞 | 装备伞后空中重新按跳跃键；再次按键收伞；拿出物品/使用物品会自动收伞 |
| 背负记录 | 真正攻击、举盾或拉弓才登记；切快捷栏不会登记新记录 |
| 锁定与目标切换 | Z锁定；左右方括号切目标；具体模式可设置 |
| 举盾 | 有实际盾时按住C，按原生盾规则格挡 |
| 近战 | 攻击键轻按或按住再松开蓄力；挖矿仍由原版处理 |
| 侧后跳/闪避 | 按方向并按X；成功反馈与实际判定、精力条件相关 |
| 技能模式 | F8调整；手动技能模式用H确认；自动/手动/关闭分别观察 |
| Fuse | V进入现有融合操作；材料按原有容量/嵌套限制处理，不保证每种物品都有独立特效 |
| 机械 | 对准节点右键安装；蹲下空手拆卸；乘坐后R启停、方向键操控、Shift下车 |

按键可在Minecraft控制设置里重新绑定；已有重绑可能与表中默认不同。滑翔手部隐藏只是操作表现，真实库存中的物品没有被删除或复制。

## 建议试玩顺序

1. 正常取得铁、铜、红石、皮革和食材，制作伞、锅、空电池和充电器。记录首次资源获取和查找配方需要的实际时间。
2. 历史最高等级提升后花掉部分经验，核对精力上限保留。穿装备、换主手与副手，再保存退出、重开，观察装备槽及红心/精力。
3. 做一份料理，核对热源、碗返还、实际效果时间。暂停和离线不消耗效果，死亡清空料理。温度当前反馈环境，未新增普遍冷热惩罚。
4. 在自然10/20/30格岩壁攀爬、放手、开伞、取弓、空中拉弓与落地。记录误触、精力变化、摔落伤害和视野；不要用无重力场景替代。
5. 对实际材料Fuse并攻击，记录材料消耗、剑耐久、剩余次数与背负显示；快速换物、打开菜单和暂停，检查旧动作会退出。
6. 旁置固定红石块为电池充电；驾驶双轮及风扇/稳定器组合50格和100格，记录实际距离、耗时及剩余电量。停止下车再回收，核对件数；随身电池不应替安装电池付费。
7. 制造机投入4铜和2红石，保存重开应保留已决定的结果，不重抽、不重扣；领取一次。核对保存后的伞位、峰值、料理余量、Fuse和机械电量。
8. 晴雨、露天/屋顶、风与开伞/翼骑乘；切GUI缩放1/2/3、中英文、F1和暂停，观察左上红心→精力→温度→料理→风提示、准星与底栏。

数值基线与实际获取记录分开。当前高级机械组合续航可能较短，需要真实路测决定是否调整，不能因自动测试通过就扩大电量或降低费用。
