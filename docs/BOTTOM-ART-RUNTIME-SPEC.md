## 选择与边界

节点1安装弹簧、浮力装置、翼或风扇时，使用该部件底部专用网格与对应主体凹舱；有效底部安装预览使用同一套几何。其他5个节点保持v01原网格、方向、支点和安装坐标。安装/拆卸、吸附拾取、真实库存、碰撞箱、能源与服务端物理全部沿用已有机制。原导出已烘焙底部偏移和刚体旋转，不再重复移动或缩放。机械安装预览沿用透明绿色，但使用真实对应图集，而非所有部件共用machine.png。

- 弹簧：保持原尺寸及.20方块源行程，底部压缩最低点距主体基底.01。主体凹舱、移动片/线圈几何同步；有效cooldown>30请求伸展，ghost始终压缩。
- 浮力装置：底部整体上移配套凹舱，最低点+.03；陆地/水中同一静态网格，无新折叠/展开或水中缩放。
- 翼：底部保持固定水平翼面与两件固定连接架，最低点+.13；不增加折叠或翼力方向规则。
- 风扇：底部偏移连同转子支点移动，保持6个转子件与固定框架/两件垫块，最低点+.03；只有原active位且非ghost时沿既有angle=age*.7转动。

电池、火箭、轮子与稳定器的底部源修正不在本轮已采用文件中，继续保留其已记录的底部边界；不能称八类底部都已修好。组合v03是支撑审核资料，不能代替实际游戏装配测试。

## 弹簧显示限位

`BottomArt.spring`读取实际客户端碰撞形状。用源网格所有带extendedQuads的移动/线圈顶点，经过与渲染相同的yaw/roll/底部基变换，得到压缩与伸展包络；在真实扫掠水平包络内查询VoxelShape表面。半砖、台阶、旋转足迹使用实际形状高度，水不是地面实心碰撞。采用保守包络，可能在边沿略早收缩以保持不穿地。

显示fraction限制到[0,1]，等价于正常直立时 `travel=min(.20,max(0,clearanceBelow+.01))`。只限制ArtMesh顶点插值，不写回冷却、armed、推进、质量、库存或存档。世界位置用double AABB移动，局部浮点变换不把大坐标直接压成float。
