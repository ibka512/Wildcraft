# C7 原生ground与移动包的只读对照

正式84/v11保持。既有P3.2验收早已记录服务端ground=true早于最终落地位置/伤害结算；本轮普通空中弓还出现高于平台时短暂ground影响原资格的记录。先观察而不修生产：记录真实handleMovePlayer服务器线程HEAD/RETURN的原包位置/ground标记、服务器坐标/AABB/脚下方块/0.01格支持碰撞、真实tick START/END与客户端GlideControls之前对应只读数据。
