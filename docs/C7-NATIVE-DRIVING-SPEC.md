# C7 普通客户端有限电池路测

状态：准备与实际验证中，以对应验收记录和JSON终态为准，不认定已通过。本批只新增隔离测试源集的普通客户端探针，生产版本仍dev62；不改变1000容量、原费用、速度、碰撞、库存、存档、输入路由或技能时间。

使用既有自动生成世界的新副本，在平直石面提供两套真实部件：双轮＋电池，以及双轮＋风扇＋稳定器＋电池。安装通过原有API转移实际物品，材料由夹具提供；不算从零采集或手工安装验收。另放一块617余量的随身电池，安装电池每套只提供一次1000，不补电或修改运行中的位移。

普通客户端不设置fabric.client.gametest。依原生瞄准和使用键乘坐，经原生R绑定状态/点击队列和前进键驱动，不冒称实体键盘/手柄测试；保持20TPS、4格实际视距和明确的闲置限帧选项。每个真实服务端刻的只读观察核对实际电池扣费，记录首次/最后扣费的刻数与墙钟时间、最后付费刻的水平路程、耗尽被观察前的无动力滑行、50/100格是否到达及当时电量、耗尽时的帧循环间隔。没有到达目标如实记录未到达，不能把到达100格当成现有规则的保证。

电量耗尽后真实R停机、Shift下车；检查原来随身617电池保持。双轮每个有效工作刻2能量，组合每刻5能量，稳态理论完整电池对应500/200次扣费；真实输入在同一世界刻的先后次序可能让组合先付3能量再付5，必须记录实际扣费分布、总和与不足一次费用的合法余量，不能强写余额0或假装所有刻都付5。首末扣费时间差自然少一个工作刻，不能直接冒称完整25秒/10秒人工续航。路径不包含人为传送/垂直落地；正常物理仍会在停机或耗尽后滑行，不能自动理解为即时刹停。

普通循环间隔不是GPU完成耗时。短平路没有覆盖自然坡地、所有部件、长时间内存、不同机器或人工驾驶手感。该结果只能补足正常时间下的已有运行规则与可复核成本；是否调电池/费用继续依据真实问题和试玩记录。
