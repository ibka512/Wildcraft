## 复现

从当前工程，先运行 `./dev.sh --no-configuration-cache runDatagen`，再运行 `./dev.sh -PacceptMinecraftEula=true --no-configuration-cache build gameTestJar`。只在操作者自行接受Minecraft EULA后使用该参数。机械核心专项为runMechanicsClientTest，全套为runPackagedClientTest，普通服务端为runPackagedServer并使用本机测试目录的既有设置。

正式公共代码在src/main/java/dev/wildcraft/mechanics，模型在src/client/java/dev/wildcraft/client/mechanics/MachineRenderer.java，可编辑像素源见art/mechanics-v1。先读P6-SPEC和P6-PREPARATION并接收安装选择，完成剩余P6矩阵后才冻结完整阶段。
