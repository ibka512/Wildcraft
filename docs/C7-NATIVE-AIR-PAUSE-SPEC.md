# C7 普通空中弓的F8暂停边界

固定正式84/v11，仅QA工具。普通自动空中弓实际5TPS拉弓付费后按F8，观察真实设置界面/单人暂停、原时间租约退出恢复20TPS；服务器确认暂停后以实际一秒窗口核对世界刻、精力、原生use刻、弹药/耐久/箭计数保持。原P3.2-RULES明确“恢复后仍符合条件可重新进入”；关闭菜单后验证新的自动会话身份与首段费用不含暂停秒，再沿原生释放/跳跃开伞、地面库存与伤害检查。原生GUI如已完成弓释放，只观察实际结果，不重新调用释放或补造箭。

不直接暂停服务器、改时钟/精力/位置/NoGravity或跳过原生物理；仅提供测试场地和材料。正常与10帧上限分开记录。失败即保留实际界面/状态和边界，不猜生产问题；未验证条件不列完成。当前真实前台/人工自然生存、长期性能、完整C6仍未完。无发布或资源采用，原包/其他美术任务不动。
