# C5 完美闪避、短林克时间与空中攻击合同

2026-10-07，基线dev.22/C4，实施dev.23，分支feature/perfect-dodge-counter。用户授权“开始下一批”；按既定C5范围实施。无新生产依赖、存档迁移、动画资产编号或GitHub发布。

## 完美闪避

仅C4已接入的原版僵尸/尸壳普通近战前摇参与。服务端接受并支付侧/后跳后，在10世界刻前摇的第6–9刻捕获同一目标、原生近战范围、视线和真实攻击资格。原生攻击将结算的时刻，玩家必须实际离开攻击者当时的原版攻击范围，水平位移至少0.25格，且经过现有侧跳移动包约束（单包水平/垂直最大0.65格、累计最多3.5格）。同一次跳跃最多领取一次，真实受伤或非法位移使资格失效。

窗口不是无敌帧。没有威胁、过早跳、堵墙不动、仍在攻击范围、隔墙、换目标、死亡/不兼容状态、伪造反击请求不能获得奖励。0.25格下限配合“必须实际离开范围”，覆盖实际单次0.32格后跳；不能用更高下限排除已经躲开的攻击。合格落空仍完成本次挥击和20世界刻冷却，不从相同前摇反复刷奖励。怪物仍原生寻路；复杂攻击体积、其他怪物/PVP留待后续合同。

## 短林克时间与反击

自动模式在真实落空后申请共用TimeLease：仅未公开局域网的单人整合服务端、恰好一名玩家，原时间高于5TPS且未被冻结/步进/冲刺时可以降到5TPS。与空中弓会话互斥；外部时间控制和原基准值保留。手动模式先给0.65秒确认机会（不减速），CONFIRM_SKILL确认后进入；关闭模式不创建会话，普通闪避仍有效。

活动持续最多1.5有效实际秒，使用现有单调ActivePlayClock，暂停不计，单次停顿补偿上限250ms；不是无限延长，也不按慢世界刻计时。只支付原侧跳8精力，无额外持续费/回血/回精力。普通移动、重力、碰撞、敌人和受伤间隔仍按原版世界刻；本阶段只补偿武器攻击恢复，不声称实现完整玩家移动实际时间补偿。

活动内一次新鲜ATTACK可请求一次反击：服务端以当前原生瞄准射线、交互距离和方块遮挡重新检查，只有指向本次威胁才命中；不自动转镜头/拉近玩家/搜寻敌人。使用原版Player.attack一次，无林克时间伤害倍率，不清空敌人受伤免疫计时，不建立连招树。未瞄准或距离不够会空挥并消费机会；重复请求不会重复结算。成功或空挥立即结束减速。Native攻击恢复计数器在活动内按有效实际秒×20推进，封顶原武器冷却；不重复tick玩家。反击后恢复仍走正常C3/原版路径。

输入与镜头按帧处理。共用Action新鲜边沿在普通tick读取前交给技能；反击前先发送原版当前视角包，再发送意图，防止5TPS时旧视角用于结算。自定义包没有客户端目标、位置、时间、伤害或费用。开始前持有的攻击不自动反击，GUI/叠层/暂停/失焦后不重放持有按键。

超时、暂停、菜单/失焦、死亡/真实受伤、维度/断线/停服、换武器/开始使用/不兼容探索、目标死亡/换目标/距离超过8格、局域网公开、其他时间控制都关闭临时会话。关闭恢复租约拥有的原速率，不能覆盖后来的外部写入。共享现有滤镜/FOV/声音；强度0仅关闭表现。

## 空中与下落攻击

剑/斧仍采用C3按住准备、松开一次原版攻击。离地释放进入独立AIR_SWING；下落距离≥2时为DROP_SWING。强化还必须实际向下运动；上升、短落差、地面不加成。下落基础倍率为min(1.5,1+0.05×真实fallDistance)，与既有蓄力倍率取较高者，最终Wildcraft倍率最多1.8，不叠乘。原版暴击、附魔、护甲及Fuse继续沿原路径，因而这个倍率上限不是包含所有附魔/原版暴击的绝对最终伤害值。

命中范围和方块遮挡不扩大；无额外落地AOE、吸附、瞬移、跌落免伤或空中连发。轻击不收费；蓄力仍剑12/斧18。挥空不扣耐久/Fuse，真实命中按原版剑1/斧2耐久及原Fuse单次效果结算。服务端不清空fallDistance。

第一人称加入小幅有界空中/下落手部姿态；第三人称及盔甲使用既有原生模型部位遮罩，保留头部瞄准、标准/纤细和左右手，不变更碰撞或用动画帧猜命中。这是程序姿态，不是C6完整动画源稿。

## 操作、设置、保存与回退

X侧/后跳、G攀爬、空中跳跃开收伞、C独立防御、Z锁定等现有默认及改绑保持。新增CONFIRM_SKILL默认H，可原生改绑；提示显示实际绑定。F8→战斗设置分别提供空中弓和完美闪避“自动/手动确认/关闭”，默认自动；旧schema1配置新增字段有默认值，保留原读写及其他设置。滤镜和技能开关是不同选项。

偏好在客户端wildcraft-combat.json保存并提交服务端；后者仍检查真实资格。捕获威胁、跳跃机会、时间租约和反击状态均临时，不写存档。历史最高经验、精力成长、专用伞槽、背负、Fuse、电池、制造结果及旧存档保持。回退前备份世界，旧dev.22包/标签/校验固定；没有新数据迁移。
