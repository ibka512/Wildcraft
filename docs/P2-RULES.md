# P2 攀爬操作与规则

用户已选择按住专用攀爬键。默认键为 **G**，可在游戏的按键设置中修改，分类为 Wildcraft。

## 操作

| 操作 | 行为 |
| --- | --- |
| 面向附近墙面，按住 G | 抓住具有碰撞面的墙 |
| G + W / S | 向上 / 向下攀爬 |
| G + A / D | 沿当前墙面向左 / 向右移动 |
| 只按住 G | 停在墙上，缓慢消耗精力 |
| 松开 G | 放手，恢复原版重力与摔落规则 |
| 向上到达开放墙顶 | 在碰撞允许时辅助越过边沿 |

横移沿墙面方向计算，转过墙角后继续沿新墙移动。初次抓墙需要面向墙，之后允许转动视角；初版不强制旋转镜头。

## 开发参数

- 常规竖直速度为每刻 0.12 格，横移为每刻 0.08 格；斜向输入归一化。
- 移动时每刻消耗 0.4 精力，停留时每刻消耗 0.1；在正常 20 TPS 下分别是每秒 8 和 2。
- 服务端还观察实际位移，不能通过发送“停留”输入获取更便宜的移动消耗。重复输入不会按数据包次数重复扣费。
- 墙面接触距离限于玩家碰撞盒外 0.08 格，使用方块实际碰撞形状，不把空气或无碰撞植物当成墙。
- 墙角辅助只跨过很小的接触间隙，仍通过原版碰撞移动；墙顶也不使用穿墙传送。
- 服务端在已授权攀爬时额外限制单次位移，保留游戏原有的碰撞、移动校验与飞行检查。
- 客户端每 5 刻续报按住状态；服务端超过 20 刻未收到新输入则放手。

上述数值用于开发验收，尚未完成生存平衡或高延迟网络调校。

## 表面与中断

普通实体方块按碰撞形状判断，包括完整方块和半砖的实际侧面。可通过方块标签 `wildcraft:unclimbable` 排除特定表面。默认排除原版攀爬方块、蜘蛛网和细雪；原版梯子与藤蔓继续使用原有行为。

水中、熔岩中、游泳、乘坐、睡眠、鞘翅飞行、原版飞行、旁观、死亡和受击状态不启动自定义攀爬。P2 没有加入雨天打滑或风力影响，天气互动留在后续阶段。

精力耗尽或实际受到未格挡伤害会放手，并锁住当前抓握。需要松开攀爬键再尝试；受击后至少等待 10 刻，精力仍须足够。继续按住不会在下一帧立即重新吸附。攀爬中不恢复精力，即使玩家脚部碰到地面。

死亡、玩家替换、切维度和重连不恢复先前的抓墙状态。打开界面或资源重载期间暂停攀爬输入；放手后恢复原版下落，不增加无条件摔落保护。

## 保存与逻辑边界

沿用 P1 格式 1 的历史等级与精力持久附件，没有改变保存字段，不需要玩家数据迁移。本轮只操作独立测试世界。

攀爬输入、墙面、抓握锁和同步状态都是临时数据，不写入存档。客户端只发送按键意图并预测碰撞移动；服务端决定接触资格、费用、中断和位移限制，只同步本人的攀爬状态。

复活处理使用明确的事件阶段，在 Fabric 自动附件转移之后执行，避免依赖模组入口注册顺序。P1 死亡补满与 P2 抓墙清理都在这个阶段完成。

初版使用原版玩家外观，没有新增专用手脚攀爬动画、攀爬跳跃、滑翔装备或生产依赖。复杂曲面、其他模组特殊碰撞、真实多人延迟和完整手感仍需后续游玩。
