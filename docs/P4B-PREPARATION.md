## 首批食材规则

使用原版食材；两至三种材料精确匹配，一份产物只消耗各有效输入格的一件，不按输入堆叠数量放大效果；排列无关。无效额外材料、重复缺料和空输入均不能生成产物，也不能静默消耗。七条首批代表配方：

| 材料 | 成品类别 | 级别/基础持续秒数 |
| --- | --- | --- |
| 胡萝卜 + 马铃薯 | 蔬菜料理 | 无附加效果 |
| 甜菜根 + 马铃薯 | 保暖料理 | I / 120 |
| 甜菜根 + 马铃薯 + 胡萝卜 | 保暖料理 | II / 180 |
| 苹果 + 西瓜片 | 清凉料理 | I / 120 |
| 苹果 + 西瓜片 + 甜浆果 | 清凉料理 | II / 180 |
| 红蘑菇 + 糖 | 精力恢复料理 | I / 60 |
| 红蘑菇 + 棕蘑菇 + 糖 | 精力恢复料理 | II / 90 |

这些是首版开发参数，需在烹饪/食用闭环完成后平衡。保暖必须有限辅助原版细雪冻结；清凉只能减轻高温反馈，不授予抗火。精力首版采用原设计建议的“提高原本允许条件下的恢复速度”，不在攀爬、滑翔或林克时间中免费恢复；临时上限、降耗保留在后续联动阶段。
