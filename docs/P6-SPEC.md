# P6 机械合同与当前开发状态

2026-10-04，feature/mechanics，源码工作版本0.1.0-dev.11。P6在本机完整验收，正式工作版本0.1.0-dev.11。用户已确认采用推荐的直接节点操作；公开GitHub仍dev.7，本阶段未上传。

## 本轮已实现的公共基础

正式命名空间wildcraft:machine；机械主体物品右键方块放置，实际创造者UUID只设置一次。尺寸1.4×0.65；原版单实体轴对齐碰撞、重力、单乘客和原版跟踪插值。禁止任意远程搬运、任意方块组合；无新增物理依赖。

六个稳定节点：0上、1下、2后(-Z)、3前(+Z)、4左(-X)、5右(+X)。随主体本地朝向旋转。服务端安装API验证存活且未移除的真实玩家、同一世界、所有者、距离≤5格及方块视线、关机、索引、占用、实际手持堆栈和部件类型；最多一个P5电池。风扇从实际手中转移一件，即使创造模式也不是复制安装。对外查询返回副本。

服务端恢复API先检查实际库存容量，成功才清空节点；满创造库存同样拒绝。运行中不能拆装；关机但未拆完不能回收主体，有乘客不能回收主体。空主体只返回一个真实物品后移除；重复调用失败。主体不受普通攻击伤害；仅创建者蹲下空手近距离直接攻击，可回收关机、拆空且无乘客的主体。

## 动力与供电

电池容量1000，沿用P5组件和原子消费。每个安装风扇每世界刻费用1，整刻总费用不足时不扣费、全部无推力；相反风扇抵消推力仍支付运行费用。只有加载且实际模拟的世界刻计算费用，林克时间沿用原版世界节奏。

每风扇加速度0.06格/刻²，反向于节点外法线；底部风扇向上，上部向下。重力0.04；水平速度上限0.4，竖直范围[-0.8,0.3]，地面/空中阻尼0.8/0.94，竖直阻尼0.98。耗尽停止推力，仍保留惯性与重力，不承诺耗尽立即刹车。碰撞轴上的速度清零。移动终点跨入未加载区块时停住且不扣当刻费用，不主动加载目的地。

所有者乘坐时原版左/右输入每刻转向3度。没有getControllingPassenger，服务器决定主体位置，客户端车辆坐标不是权威输入。空手右键乘坐，A/D转向，默认R启停，蹲下离开；启停键可在原版按键页重绑。乘坐中止攀爬与滑翔。

## 保存与同步

新机械自身格式1：wildcraft_schema、wildcraft_owner、wildcraft_parts(恰好六个完整ItemStack)、wildcraft_enabled；位置、朝向、速度和乘客使用原版实体保存。新格式不修改精力、滑翔、背负、料理或电池旧格式。未知机械格式或错误节点清单拒绝载入，不截断清单来丢物品；只在专用测试世界运行，未迁移真实存档。离线不补电、不补扣费用。

原版SynchedEntityData只向实体跟踪者同步风扇位图、电池节点、电量、启用和实际运行标志；不发完整部件名称、任意组件或玩家库存。原始完整组件只用于真实保存和回收。客户端原创主体网格、安装件、旋转叶片与电量条从提取状态绘制。

## 生存配方与资产

主体：铁锭6、铜锭2、橡木木板1；风扇：铜锭3、铁锭1、红石1。P5电池和充电器配方不变。原型像素源和导出器在art/mechanics-v1及art/tools/generate_mechanics_art.py；实际网格为可编辑MachineRenderer.java。伸出的部件仅有外观，碰撞仍是一个主体；风、复杂倾斜与复合碰撞属于后续范围。

## 已确认的玩家操作

用户在2026-10-04回复“按你推荐的来，不要询问我，你现在可以继续开发了”，采用直接节点安装，无专用工具或节点菜单。手持风扇或电池指向空节点右键，实际转移一件；浅绿色吸附预览为本机提示，不能代替服务器授权。关机时蹲下空手指向已占用节点右键拆下。指向空节点不会启停；蹲下空手点顶部绿色控制板才启停。空手站立右键乘坐；骑乘时机械启停键（默认R）走无参数意图，服务端取实际乘坐主体。

原版实体交互包的命中坐标只作提示：服务端从真实眼睛、朝向与原版交互距离重算实体面，拒绝非有限坐标或与真实射线差距超过0.3格的伪造命中。所有者、存活、方块视线、库存和开关仍由服务端检查；2世界刻动作间隔避免同一批启停重复翻转。新启停包不接受实体编号、客户端电量或最终位置。

创造模式安装同样转移真实一件。原版Player.interactOn会恢复同一手持对象的数量，所以安装后将真实余量放回手中，避免原版包装器恢复已安装的一件。回收仍保留真实容量检查，不使用创造模式删除余量的语义。

完整P6验收矩阵见P6-PREPARATION；基础证据P6-CORE-VERIFICATION是上一轮历史，完整玩家入口与两客户端验证另行记录。P7剩余六类部件、制造机、Fuse、天气继续按路线实施，不把风扇切片当作全部机械完成。
