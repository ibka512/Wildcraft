# C6B：原生长矛接入合同

基线 dev.24，目标 dev.25，2026-10-07。本批将七种原版长矛接入统一近战输入、蓄力、Fuse、实际使用背负及程序突刺姿态。只接受木、石、铜、铁、金、钻石、下界合金原版长矛与原生贯穿组件；第三方或任意添加组件的物品不自动支持。没有新增生产依赖、美术采用ID或存档迁移。

短按释放轻击，按住18世界刻再释放强击；轻/强恢复8/13世界刻，强击消费16精力，基础倍率1.4、额外击退0.2。原生最小攻击恢复检查继续使用服务端原生容差5，强击另要求90%恢复及足够精力。取消、换物、原生使用、GUI/失焦和重复意图沿已有合同。方块起手保留原版输入，实体/空气起手由统一手势拥有；不能泄漏第二份原版STAB包。

一次主手攻击调用原生 PiercingWeapon.attack，再由原生 Player.stabAttack 逐目标结算，不能用最近单目标 Player.attack 替代。静止生存攻击区间2～4.5格，创造上限6.5格；原版移动范围延伸、碰撞余量、墙体截断、贯穿、击退、原生附魔与耐久继续按原版计算。原版长矛没有剑的横扫或普通暴击，本批不新增这些效果。强击倍率只作用基础伤害；融合伤害沿原版附魔增量路径与攻击冷却，不重复乘上强击倍率。每个实际受伤目标消耗一次融合材料；原生耐久按每个实际受到原生攻击影响的目标结算，免伤与击退可能使两者不同。

原版次要使用走 KineticWeapon，保持速度条件、联系目标记忆/冷却、伤害与卸骑；不叠加本批主攻击蓄力/Fuse基础伤害。真正造成SPEAR伤害后才施加材料效果与消耗。主手与副手速度攻击均取正在使用的真实堆栈，背负记录跟随该堆栈，不误消耗主手其他装备。没有新副手近战手势。

C5反击继续要求实际准星中的有效同一威胁；长矛检测使用原版范围与遮挡。在恢复后的有效实际时间窗口内沿原版贯穿出手一次；落空时只执行原版空挥收尾，不能另发贯穿射线伤害无关目标。原生贯穿本身仍可能命中同一直线上的多个合法目标。

第一/第三人称复用已有三叉戟式有界突刺姿态和原版STAB动画，标准/纤细、左右手、四槽盔甲及头部瞄准保持。长矛物品展示使用原版纹理：GUI/地面/固定/货架16像素图的矛尖在右上；手持32像素图的矛尖在左上，融合附着分别取对应端点。背负复用现有长柄布局与鞘翅侧腰处理。未复制原版贴图进采用库，完整动画源稿、第一人称双手握持、独立取收剪辑仍待后续。

MeleeWeapon 瞬态类别末尾追加SPEAR/id4，双端开发包版本应一致；已有精力、Fuse与背负持久数据格式不变。验收需同时覆盖原生一次调用、每目标耐久/融合次数、区间/墙/旁观者、强击/费用、替换/使用/冷却、附魔/组件保存与回收、副手归属，以及真实客户端按键队列和C5反击。最终状态以 C6B-VERIFICATION.md 与实际日志为准，规格不是通过证明。
