# P3.2 林克时间操作与保存规则

版本 `0.1.0-dev.6`，Minecraft 26.3 / Fabric。完整合同与参数见 [P3.2-SPEC](P3.2-SPEC.md)，实际证据见 [验证报告](P3.2-VERIFICATION.md)。

在未开放 LAN 的单人生存世界，从高处落下或跳起时按住使用键实际拉弓即可触发。松开射箭，换掉实际使用的弓、落地、精力耗尽或资格消失时退出。弩暂不触发；不需要新技能键或新资源。精力沿用左上角已有显示。

缓降仍累积摔落距离，连续开关拉弓不能免摔落。滑翔需要先结束拉弓；滑翔中实际取用弓按既有规则收伞。按住攀爬键会阻止或结束林克时间。普通移动仍不扣精力。

F8 打开画面设置，可以在原版按键设置里重绑。支持总强度关闭/弱/标准/强及独立暗角、准星、边缘纹理、低精力轻闪和轻微 FOV。轻闪、纹理、FOV 默认关闭。滤镜关闭后时间与精力照常生效；第一/第三人称均可，视角不锁定。

暂停时结束慢动作且不收费；恢复后仍符合条件可重新进入。开放 LAN 在发布入口先恢复进入前速度；LAN 和独立服务端保留原版弓行为，不触发此技能或收费。外部时间控制接管后不覆盖对方速率，当前拉弓需先结束才能再次触发。

技能会话、时钟、租约、同步显示、临时使用阻止记录不保存。客户端设置存放在 `config/wildcraft-focus.json`，独立格式 1；原玩家精力、伞槽和背负格式不变。本轮没有个人存档迁移。回退使用匹配旧版本与测试前世界备份，不能把未发布阶段等同长期升级支持。
