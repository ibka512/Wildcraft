# 单人生存数值基线

2026-10-06，dev.17 / P10.2。本轮记录测量与人工验收方法，不改变费率、容量、成长公式或旧存档。本表中的秒数按正常20TPS换算，服务器卡顿、林克时间、卸载和实际驾驶状态会改变墙钟续航。

## 精力

| 行为 | 当前规则 | 峰值0 / 峰值20的理论持续时间 |
| --- | --- | --- |
| 上限 | 100 + 2 × 历史最高等级；消费当前经验不降低 | 100 / 140 |
| 攀爬移动 | 0.4/世界刻 | 12.5秒 / 17.5秒 |
| 抓墙停留 | 0.1/世界刻 | 50秒 / 70秒 |
| 滑翔 | 0.2/世界刻 | 25秒 / 35秒 |
| 空中拉弓林克时间 | 10/有效实际秒 | 10秒 / 14秒 |
| 普通恢复 | 等待20世界刻后1/刻，满足既有地面等资格 | 从空到满约6秒 / 8秒（含等待） |
| 恢复料理I / II | 在原有可恢复条件下1.5倍 / 2倍 | 不在空中免费恢复；不提高永久上限 |

移动攀爬约0.12格/刻，无障碍理想直线约30 / 42格；这不是实地攀爬保证。普通走、跳、跑、游泳不新增精力费。自动单人流程保留峰值20而将当前等级消耗到0，验证上限仍140。

## 获得成本与目前疑点

逐项原料见[SINGLEPLAYER-RECIPE-COSTS.csv](SINGLEPLAYER-RECIPE-COSTS.csv)，直接从当前14份配方统计。原料名字为注册ID，省去语言混淆；锅的桶、浮力装置的橡木船、制造机的炉和红石块需要额外原版合成，表中不假装已拆算所有上游成本。

本轮原料场景的套装包括伞、锅、空电池、充电器、主体、2风扇、2轮、弹簧、翼、弓、铁剑、2红石块、制造机。原版工作台消耗42铁锭、20铜锭、23红石，另用已提供的桶/炉等原料；原生制造一次再消耗4铜锭＋2红石。场景布置不代表从零采矿获取成本。

当前重点疑点是高级组合的满电续航只有10秒，单一固定源满电仅2.5秒，可能形成频繁往返充电的节奏；是否需要调整必须以目标距离和实际手感判断。先按[SINGLEPLAYER-PLAYTEST](SINGLEPLAYER-PLAYTEST.md)记录，不能凭理论表直接扩大电池或降低成本。料理时长为有效实际时间，不能与世界刻续航混为同一种计时。
