# C6E：连续玩家骨架第一批运行接入

2026-10-12，本机开发。接续F07/dev.28，feature/adopted-art-runtime；本批没有公开发布权限。

## 本批行为

使用已采用的climb-up/v02闭合标准/纤细22骨骼蒙皮作为共同皮肤网格。locked-idle/v02与sword-regular/v02的20骨骼源动作转换到同一骨架；腕骨继承前臂与22骨骼绑定关系。只抽取12个身体/皮肤外层网格，不保留参考人物检查皮肤、剑盾几何或作者工程。

第一批正式选择：地面静止、无盔甲、空副手、无可见披风的锁定待机（左右手）与普通剑单击（左右手）。权威仍为现有Combat与MeleeActions，读取角色皮肤、实际主手、世界状态和实际阶段；不新增攻击判定、伤害、费用、连击、输入包或存档数据。普通剑素材的B/C/Combo和reviewOnlyTiming不是玩法授权。

源动作A包含起止待机及衔接，游戏播放只取0.65–2.05秒的单击/恢复区间，按既有权威阶段归一化映射；素材2.8秒不改变游戏攻击时间。进入与换剪辑有有界衔接，解锁淡出；GUI、装备、空中、使用与不支持动作立即交回原有表现。待机采用有效本机时间，暂停冻结。原先五类武器第一人称握持与取收表现仍保留，此批连续蒙皮为第三人称全身。

## 实际皮肤与装备

绑定AvatarRenderState中的原版玩家皮肤，标准/纤细选择相应闭合网格，袖子、帽子、外套、裤子按原生可见设置显示。头部保留独立瞄准。

真实剑仍使用原生ItemStackRenderState，只解出实际原生模型的柄部位置与轴向，投影到源稿左右剑参考握点；不复制库存、不生成参考剑、不缩放原版武器。Fuse附着仍在同一个真实物品模型中。背负装备若出现，沿同一身体变换附着。

Avatar抽取顺序：原生与现有Wildcraft层1000 → 测试专用皮肤夹具1400（正式JAR没有）→连续骨架快照1500。每个Avatar快照与GPU延期提交相互独立，不改原生共享玩家模型。盔甲、占手、披风、移动、蹲伏、受伤、空中、攀爬、滑翔、举盾、其他武器及取收暂用既有路径；这些限制不等于对应正式美术已完成接入。

## 资源与来源

离线转换：`tools/import-player-combat-art.py`，默认生成试验资源；`--runtime`生成`src/main/resources/assets/wildcraft/animation/{standard,slim}-combat-rig.json`和provenance。Python/numpy仅离线工具，未新增生产依赖。运行数据schema1，22蒙皮骨＋6握点/装备参考骨，8份源剪辑；第一批只选择4份待机/单击，不启用4份盾兼容动作。

转换后读取校验数值有限、索引、权重归一化、帧/矩阵形状。源数据与输出SHA-256保留。缺少本机受限资源的公共源码检出保持现有玩家模型；损坏的实际拥有资源抛出明确错误，不假装正确加载。

待机包含Kevin Iglesias派生动作，剑动作Quaternius CC0但继承待机；不能将整个运行资源宣称CC0。源许可见`art/player-animation-v1/locked-idle/v02/licenses/SOURCE.md`与`sword-regular/v02/licenses/SOURCE.md`。本机转换资源与包含它们的JAR仅本机验证；未来上传须重新审查、过滤许可，不能直接上传完整派生动作素材包。
