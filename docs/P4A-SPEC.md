# P4A 环境温度规格

日期：2026-10-04。开发版本：`0.1.0-dev.8+mc26.3`。这是环境反馈首版；P4B 料理与有限细雪辅助另行实施。保持 Minecraft 26.3、JDK 25 和现有 Fabric 依赖。

## 玩法边界

温度表示当前位置的环境冷热，**不是摄氏度、体温、饮水或第二条生存资源**。普通冷热不新增伤害、移速变化、精力费用或恢复惩罚。原版火、岩浆、细雪冻结、皮革装备保护及摔落危险照常；首版没有保暖/耐热料理，也没有抗火或岩浆免疫。

七档依次为极冷、寒冷、偏冷、舒适、偏暖、炎热、极热。文字与七格短指示共同表达状态，不只依赖颜色。读数位于左上角红心/精力之下，跟随红心行数；不改经验、饥饿与骑乘显示。F8 现有画面设置增加独立“温度边缘色调”开关，关闭只影响色调，读数和游戏行为不变。

## 服务端计算

相对指数限制在 `[-3, 3]`。以下数值为首版可调开发参数，不是现实气候测量：

| 场景 | 基础指数 |
| --- | --- |
| 原版群系气候值 ≤ 0（雪原等） | -2.8 |
| 0 < 气候值 < 0.25 | -1.8 |
| 0.25 ≤ 气候值 < 0.5（针叶林等） | -0.8 |
| 0.5 ≤ 气候值 ≤ 0.8（平原等） | 0 |
| 0.8 < 气候值 < 1.5（丛林等） | +0.8 |
| 气候值 ≥ 1.5（沙漠等） | +1.8 |
| 下界 | +3 |
| 末地 | -0.8 |
| 未知/第三方群系 | 中性 0 基础值，仍计算当地水、天气及热源 |

天气采用锁定版本原版 `precipitationAt`：必须实际下雨/下雪，当前位置露天且未被挡雨方块遮蔽，群系也允许对应降水。当地雨 -0.25，雪 -0.35；沙漠不因全局雨天自动降温。浸水 -1.2，离水后恢复；不增加离水“潮湿”计时或状态。

局部热源为已点燃营火、火/灵魂火、岩浆流体；强度分别 1.4、1.8、2.4。以玩家身体附近采样点到方块中心的距离计算，四格半径内线性衰减，四格以外不影响。碰撞遮挡阻断热源；采用最强可见源，**不相加**，堆放火源不能无限升温。热源不授予伤害免疫。

先算基础 + 当地天气 + 水 + 热源，再限制到指数范围。本人附件只同步一个量化至 0.01 的浮点目标值；没有客户端上传最终温度的接口。

## 生命周期、性能与保存

- 每位存活、非旁观玩家每 10 个世界刻采样一次，按实体错峰；20 TPS 通常约每 0.5 秒，林克时间 5 TPS 时约每 2 秒。没有为温度额外推进世界/玩家刻。
- 进入游戏、复活、切维度重新采样。值未变化不重复发布。死亡、旁观或位置区块未加载时移除视图。
- 只读取已加载区块，不为温度生成/加载区块。热源候选最多检查半径四格的 9³ 方块位置（729 上限），再按球体距离筛选；每次最多 16 条遮挡射线，跨区块射线先检查路径所涉区块。
- 高密度遮挡场景只检查排序最强的最多 16 个候选，可能保守忽略更弱的可见源；不保证完整房间热传导模拟。
- `temperature_view` 瞬时、仅本人同步、不持久化、不死亡转移。旧精力/伞槽/背负格式 1 完全保留；不增加真实存档迁移。
- 本机 `config/wildcraft-temperature.json` 格式 1 只保存色调偏好；现有 `wildcraft-focus.json` 不改格式。断开连接清空 HUD 缓存；重连按当前位置重新获取环境。

## 显示过渡与画面优先级

HUD 使用帧级单调时间指数平滑，时间常数 1.2 秒，每帧最多计入 250ms；单人暂停停止平滑，长卡顿不补算全部时间。不同帧率同等有效时间得到相同过渡。初次世界/玩家/维度视图直接按当前环境初始化，避免沿用旧世界读数。

档位中心为 -3、-2、-1、0、1、2、3，分界为半整数，额外 0.12 回差抑制临界来回闪烁。原版群系基础值安排在相应稳定档内；雪原 -2.8 可从舒适稳定进入极冷。画面只在左右最外侧各 4 个 GUI 像素添加冷蓝/暖金色调，最大透明度 14/255，不覆盖瞄准中心，不新增闪光、FOV、全屏滤镜或声音。林克时间期间只暂停该色调，保留温度短读数。

温度样式是首版直接绘制的短指示，无新下载依赖或借用游戏外美术；后续原创图标可以在不改变规则的前提下替换。

## 诊断与验收

管理员可使用 `/wildcraft temperature status [玩家]` 查看即时相对指数、基础/天气/水/热源修正和扫描计数。这是只读诊断，命令的即时档位可能领先仍在平滑的 HUD。

验收覆盖真实群系/当地雨雪与遮蔽、水与离水、营火点燃/熄灭/距离/墙体/非叠加、下界、平滑/回差、多行红心和精力、滑翔、林克时间色调优先、偏好保存、本人网络隔离、切维度/重连、无持久温度和无额外玩法惩罚。证据与可信范围见 [P4A-VERIFICATION](P4A-VERIFICATION.md)。
