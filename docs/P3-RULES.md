# P3 滑翔伞操作与规则

用户确定的设计：新增独立滑翔伞装备位，装备后在空中按跳跃键开收伞；滑翔时双手持伞，取用物品会自动收伞。

## 获得与装备

物品 ID 为 `wildcraft:paraglider`，生存合成使用 3 个皮革和 4 个木棍：

```text
皮革 皮革 皮革
木棍  空  木棍
木棍  空  木棍
```

获得皮革会解锁配方书条目。滑翔伞每格最多一个，P3 不消耗物品，也没有耐久费用；消耗的是玩家精力。

普通物品栏的装备区域增加一个带伞图标的专用槽，位于人物预览右上方、副手槽上方。该槽只接受滑翔伞，不占用护甲或副手位置。可以普通点击装卸，也可以用 Shift 快捷移动；满背包不能强制取出或吞掉装备。创造物品栏的个人装备页也提供该槽。

放在普通背包、快捷栏或容器中的伞不能使用。只有专用槽中的伞才满足开伞条件。

## 操作与双手

| 操作 | 行为 |
| --- | --- |
| 装备滑翔伞，在空中重新按跳跃键 | 开伞；默认是空格，跟随原版跳跃键改绑 |
| 已开伞时再次按跳跃键 | 收伞，恢复原版重力 |
| 移动视角 | 改变滑翔方向，低头不能制造升力 |
| W / S | 加快 / 减慢向前移动 |
| A / D | 侧向控制 |
| 切换快捷栏、攻击、使用物品、交换副手或丢物品 | 自动收伞，再进行原版动作 |
| 落地、受击、耗尽、装备被取出 | 自动收伞 |

从地面一直按住跳跃键，不会到空中自动开伞；需要一次新的按下动作。挂墙时可以按跳跃键转为滑翔，抓墙结束，两种模式不会同时消耗精力。再次抓墙仍遵守 P2 的松开后重抓规则。

开伞时双手的物品在第一与第三人称中暂时收起，第三人称显示双手抓伞架。物品仍保留在原本的格子中，不搬动、不丢弃，也不修改数量、附魔或其他组件。玩家重新选择或尝试使用物品会收伞；服务端也检查手中状态变化和实际使用、攻击动作。

打开界面或资源重载期间收伞。死亡、重连、世界重开与切维度不会自动恢复开伞，需要在具备条件时重新操作。

## 开发参数与边界

- 每服务端刻消耗 0.2 精力，正常 20 TPS 下为每秒 4。重复网络输入不会重复扣费，滑翔中不恢复精力。
- 固定下降每刻 0.08 格，约每秒 1.6 格；默认前进每刻 0.16 格，W 为 0.24、S 为 0.08，侧移最多 0.12。
- 通过原版碰撞移动，碰撞盒仍是玩家身体。伞模型当前不单独产生实体碰撞。
- 只在已获服务端授权的滑翔期间清除累计摔落距离。收伞、耗尽或受击之后重新开始计算原版摔落，不提供永久保护。
- 不在水、熔岩、游泳、乘坐、睡眠、细雪、旁观、死亡、受击或激流旋转状态中开伞。漂浮效果保留原版行为。
- 创造飞行权限与装备了原版滑翔组件的情况优先保留原版操作；P3 的正常测试与玩法使用生存模式。
- 输入每 5 刻续报，20 刻超时关闭；被中断的请求不会靠心跳自行重新打开。受击或越界位移至少有 10 刻冷却。
- 不加入风、上升气流、雨天影响或伞升级。这些仍按后续路线推进。

移动数值、伞架外观与手感是开发参数，尚需长期生存和多人延迟调校。

## 保存与回退

P1 玩家历史等级与精力仍使用格式 1，字段没有变化。新增独立的 `wildcraft:glider_equipment` 持久附件，格式 1，保存完整物品堆栈及组件。旧玩家没有此附件时得到空槽，不搬动已有背包中的伞，也不迁移真实玩家数据。

普通死亡且未开启保留物品时，装备伞掉落一次并从装备位移除；开启保留物品时随玩家保留。存活替换、切维度、重连和重启保留装备。开伞、输入和冷却属于临时状态，不保存为可自动恢复的飞行。

装备通过原版菜单操作并由服务端验证，状态同步给本人；伞的开合外观同步给跟踪该玩家的客户端，精力数值仍只给本人。

本轮存档检查使用专用测试世界。升级个人世界前保存世界备份。回退到 P2 时恢复对应备份和 JAR；不要只替换旧 JAR 后继续保存含新装备附件的世界。
