## 烹饪循环

用七块铁锭和一个桶合成料理锅（`I I / IBI / III`）。右键打开原版容器协议菜单，三格食材、空碗格、成品格。锅下有点燃营火（含灵魂营火）或火焰时自动烹饪，100 世界刻；世界减速也减慢烹饪。熄火、无碗或成品占位暂停；食材组合改变则清零进度。完成时每个占用食材格与空碗各扣一件，再提交一碗固定结果。没有随机重抽。

不匹配食材不收费，成品占位不收费，菜单不能放入成品格。Shift 取出遵守剩余库存空间。破坏锅走原版容器掉落一次；锅自身由战利品表掉落。输入、成品、进度和待完成配方随方块实体保存；重载复核当前食材。新物品/方块 ID 稳定保留，旧玩家格式 1 不变。回退应使用升级前世界副本，旧包不认识新增方块和物品。

## 效果与时间

- 三类可并存。同类强度较低时保留现有强效果及余时；同强取现有余时/新基础时长的最大值；强效果替换弱效果，使用新料理时长。不相加、不无限叠倍。
- 精力恢复 I为1.5倍，II为2倍。只在原有允许恢复的条件下生效，保留等待、上限与历史等级；不在空中、攀爬、滑翔、专注或水中免费恢复。临时上限/技能折扣留到P9.1。
- 保暖 I仅每2世界刻、II每3世界刻允许原版细雪冻结增加；不清除已积累冻结，不免疫完全冻结伤害，不改变皮革保护或离开细雪后的恢复。
- 耐热仅减弱温度热色调，保暖仅减弱冷色调（I二分之一，II三分之一）；环境读数和实际火/岩浆危险不变。耐热没有抗火能力。
- 服务端单调有效时钟，单步最多250ms，与现有专注时钟同样舍弃更长卡顿；离线无时钟，暂停入口显式锚定，恢复首步不扣暂停间隔。5TPS下仍按实际有效秒数到期。有限数据格式1保存剩余毫秒，重连不刷新基础时长；死亡清除，存活换维度保留余时并重锚。
- 私人视图只发三类强度与向上取整秒数，变化才同步；HUD位于温度下方。客户端没有提交强度/时长的接口。无新的共享静态客户端玩法状态。
