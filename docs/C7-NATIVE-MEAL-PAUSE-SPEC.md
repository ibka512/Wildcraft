# C7 原生暂停/离线的两种计时

固定正式dev82。料理使用ActivePlayClock有效实际毫秒，制造使用100世界刻；均须在正常单人暂停时冻结，料理离线不扣时。现有代码仅只读核对：MealItem原生finishUsing应用MealData并返碗，alwaysEdible无需改饥饿；IntegratedFocusMixin在暂停循环调用CookingEffects.paused防止恢复时补扣间隔。

只在新生成的纯API测试世界副本提供安全平台/制造机/8铜4红石和一份60秒耐热料理，原生吃完返1碗，不直接调用eat或设料理效果。原生制造按钮开始同一任务，再用真实F8设置菜单暂停，确认客户端/服务端均paused后读两次权威状态，实际间隔至少3秒，世界刻、制造进度与料理毫秒应完全不变。恢复约1.5有效秒，料理只按实际活跃秒推进，制造按真实世界刻推进。

原生停止时只读记录实际最后剩余毫秒/世界刻/已付制造结果。另一进程原磁盘副本重开，比较料理损耗上限为本次加入后的真实活跃时间（含正常调度余量），不能扣掉停机/启动资源加载的墙钟；材料/已定结果/碗仍守恒。保留全部失败或实际未完成限制，不用本机系统锁屏替代游戏暂停。

这个是程序提供材料/原生绑定和菜单回调观察，不是人工料理制作或前台性能；不改旧Clock/250ms步长/物理/伤害/费用/存读/技能时间，不新增依赖、美术采用、真实存档迁移或上传。额度全部>5才开发，任一<=5只保存与实际reset+60秒续跑。
