# P5 红石能源与有限电池

本阶段承接用户连续开发授权与路线既有决定，保持版本、依赖和旧存档格式。固定放置在世界中的原版红石块是无限储量能源，红石信号只表达控制状态，不能当作电量。移动机械没有随身无限能源；P6安装后的机械依靠有限电池。

## 实施方向

- 增加有限电池物品、充电器方块和原版协议菜单。初版电池容量1000能量，合成仅用铁、铜与红石；初始0，不能在合成、放置、掉落、菜单转移或重载时回满。
- 每个固定红石块每世界刻最多输出20能量，邻接多个充电器共享这个上限，合格充电器轮流获得供电，避免先到者永久垄断。只查看已加载邻接格，不远程找源、不加载区块。
- 一个充电器每刻最多接受20，电池充满停止请求。不接受只有红石线、火把、拉杆或信号强度的地点；插槽里携带红石块不能供电。加载后当场重新判断世界方块，不保存“曾经有无限源”的权限。
- 电量存储在实际电池堆栈组件 `wildcraft:battery` 格式1中，0..1000，最多一件。正式服务端充/放电函数返回实际转移量；不足时原子拒绝要求整笔费用的操作，未知/非法数字不生成能量。
- UI显示数值与短条，物品提示显示余量/容量。未来P6通过这一个堆栈组件消费，不复制临时电池数值，也不改玩家精力。
- 充电器以世界刻工作，单人暂停停转、林克时间减速也降低每实际秒输出。与有效实际时间的料理效果明确分开。

## 验收

固定源限速与多充电器公平、红石信号无电量、载具/物品中红石块无无限源、完整充电/取出/有限消费/重新充电、满容量、空容量、非法输入、成品堆栈保存与掉落、充电器库存及破坏回收、重载不补满、真实客户端菜单和显示、无测试模组独立服务端、历史探索玩法回归。P6前不声称完整移动机械已经实现。

模型与图标先使用原创可编辑功能原型，正式美术单独制作验收。

## 合成与实际边界

电池配方`ICI / CRC / ICI`（铁4、铜4、红石粉1），充电器`ICI / CRC / III`（铁5、铜3、红石粉1）。I=铁锭，C=铜锭，R=红石粉，使用原版工作台，合成结果为空电池。充电器右键打开，只有一格电池，Shift转移走原版库存协议。最多2.5有效正常世界秒充满，首版数值属于后续平衡参数。

源按六邻接格查找，每源每刻只给当刻轮到的充电器一次额度；若仅剩少量容量，未用额度不存储、不转移。候选发生变化时也不能重复领取当刻源额度。多个固定源仍受单个充电器20/刻上限。只存在P5充电器负载；正式机械的供电调用在P6接入，不能声称所有移动载具已验收。
