举盾调用真实原版手中盾牌使用状态，优先副手，否则主手；不搬运、复制或创建装备。原版格挡延迟、有效范围、耐久、冷却和Fuse盾效果仍执行一次。锁定时盾牌有效正面跟随目标，未锁定时沿原版瞄准方向。普通举盾/格挡不新增精力费用。潜行与防御独立，可同时使用。原版USE/拉弓优先，独立防御不会夺取其他物品使用；盾被替换/破坏/冷却时取消且需松开C重新开始，超时20世界刻或断线释放。
