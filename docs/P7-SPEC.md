## 首批实现：翼与轮子（正在验证）

沿用P6六节点、所有权、真实物品转移与完整ItemStack格式1。新部件种类视图每节点4位，仅发类型；原风扇位图和电池视图保留。非空节点一律阻止主体回收，不只检查风扇/电池。旧六节点格式1仍可读取，回退请使用世界备份，因为旧包无法读取新的部件物品。

翼为被动滑翔面，不耗电、不提供上升力。水平速度超过0.12格/刻且下降时，竖直下降速度最多为0.12×载重/翼数；载重=1+0.1×部件数+0.25×乘客数。低速仍受完整重力，不悬停；翼空气阻尼0.98，原水平速度上限0.4和原版碰撞保留。首批载重只限制翼下降能力，其他动力载重在剩余部件合并时统一校准。

轮子仅在实际接地且有驱动方向时参与供电；每轮每世界刻费用1，与风扇整笔原子消费。有人乘坐时原版W/S控制前后、A/D转向；无人且启用时朝主体前方自动驱动。每轮加速度0.05格/刻²，地面阻尼和上限沿用P6。只有启用、实际供电且接地的轮子启用原版最大1格台阶高度；墙面碰撞仍保留，离地不驱动。

原创原型源图为art/mechanics-v1/wing.pixels.json和wheel.pixels.json，标准库导出器生成PNG；实体外观为MachineRenderer的可编辑几何。翼配方皮革2、羽毛1、橡木木板3、铜锭1；轮子铁锭4、铜锭1。
