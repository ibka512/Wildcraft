短按松开轻击，长按松开强击；只拦截实体/空气起手。方块起手原生挖掘，原生USE不改为Wildcraft蓄力。相同堆栈、世界刻心跳/恢复、真实准星和原生距离/遮挡、取消/互斥沿C3/C5。强击要求原生攻击恢复≥90%和足额精力，空挥收费一次，重放包不重复伤害或费用。物品种类服务端从真实堆栈判定，客户端不发送类别、目标或伤害。不得把所有物品当剑。

三叉戟沿原生Player.attack一次；不增加距离，不改投掷、忠诚或激流。重锤沿同一路径；合格原生smash（真实fallDistance>1.5且非鞘翅滑翔）优先，保留原生下落奖励、径向击退、命中后摔落重置。该smash不启用Wildcraft额外强击费用/倍率/击退，也不叠加C5下落倍率；原生本身的高处伤害保持，未声称改成Wildcraft上限。地面与非smash出手才使用重锤独立强击参数。普通未命中smash保留原生摔落风险，动画不重置掉落。

Fuse新增宿主仅原生三叉戟/重锤，保持原保存组件/32使用次数/分离回收。基础附加伤害仍沿原生攻击冷却、暴击、附魔、护甲，真实PLAYER_ATTACK或真实持锤MACE_SMASH伤害才触发材料效果与消耗；每个真实受伤目标消费一次。三叉戟投掷保留原生物品组件，不在本批新增投掷Fuse效果或将其冒称近战。背负沿近战一个视觉引用，实际近战伤害才登记，不增加槽位或改变最近使用规则；长柄与锤分别布局，披风/鞘翅沿侧腰。

锁定版本原生DataComponents.PIERCING_WEAPON使用PiercingWeapon.attack→Player.stabAttack，支持最小/最大距离与贯穿，原生STAB操作/次要使用均独立。该组件优先排除Wildcraft手势与新Fuse宿主，避免标签把长矛误分成剑；后续专门整合并验证，不改原版贯穿为最近单目标。

程序姿态：三叉戟前向准备/短突刺，重锤双臂准备/慢恢复、更多躯干参与；标准/纤细与左右手保留头部。第一人称复用原生武器模型并有界变换；完整双手握持源稿仍待制作，重锤姿态不能作为最终美术验收。动画不拥有伤害。原生盔甲继续一次同遮罩，已有滑翔/攀爬/弓/盾优先，原始动作清单与32项状态见animation目录。
