# P8 古代装置制造机准备

在P7完整验收并冻结后实施，工作版本升为dev.13；此文保留准备过程；正式实现与验收见P8-SPEC/P8-VERIFICATION，当前已完成制造机。用户已授权按推荐路线连续开发；沿用原规划“投入原版红石等资源，随机获得机械部件”，不增加生产依赖、矿石体系或公开发布。

首版建议固定消耗4铜锭+2红石，每批只得1件。八类部件均等权重1，总权重8；电池为空电，火箭为80刻未点燃，弹簧为初始已复位。主体继续单独合成，空壳不进入池。界面明确显示成本、范围和概率。

两个投入槽、一个产出槽，按制造按钮启动。服务端同一操作先验证材料/空产出/无任务，再确定一次完整成品并同时扣材料，保存结果与100世界刻进度。已确定结果不随界面重开、暂停、离线或重启重抽；无加载模拟时不推进。满库存不发地面奖励，产出保留机器内，旧产出未取不能新开。

制造机拆下时应由同一真实机器物品携带库存、已确定任务与进度，再放置恢复；不提前完成、不退款重抽、不另掉一份内容。使用26.3原版BlockEntityData/loot组件，先核实固定本地源码与原版搬运机制，防止与默认容器掉落重复。不同玩家共用服务器同一台容器，重复/并发按钮不会创建第二笔任务。新增保存格式1只影响新制造机；不迁移已有玩家和机械数据。

顺序：制定P8-SPEC → 原版方块/容器/服务端任务/原型资源 → 真实投入制造取出 → 重复、满库存、破坏回收、重载与联机检查 → 完整回归和独立服务端 → 冻结阶段，再继续P9正式Fuse。任一有效额度窗口余量≤5%则保存未完成检查点并停止。
