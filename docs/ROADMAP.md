# Wildcraft 开发路线（规划 v2）

更新：2026-10-06。最新执行顺序、阶段验收和第一批任务见 [后续开发计划](NEXT-DEVELOPMENT-PLAN.md)；完整设计背景见 [开发规划 v2](DEVELOPMENT-PLAN-V2.md)。本页为执行索引，旧路线保存在 [历史快照](ROADMAP-before-plan-v2.md)。

## 当前基线

P0、R0、P1、P2、P3、P3.1 与 P3.2 已完成本机验收；R1 已完成隔离实验，见 [研究结论](R1-FINDINGS.md)。当前本机游戏版本为 `0.1.0-dev.15`，第二批29项采用美术已接入，P4A环境温度、P4B料理、P5能源与P6/P7机械及P8制造机/P9正式Fuse已完成；公开 main/Release 仍为 dev.7，尚未上传本次改动，历史包保留。P3.1 交付三类背负和左上角红心/精力，见 [本阶段验证](P3.1-VERIFICATION.md)。保留 Minecraft 26.3 / Fabric / JDK 25 / macOS 开发环境。单人林克时间见 [P3.2 规格](P3.2-SPEC.md) 与 [验证](P3.2-VERIFICATION.md)；温度规则见 [P4A 规格](P4A-SPEC.md)，验收见 [P4A 验证](P4A-VERIFICATION.md)。

## 调整方向

- 2026-10-06用户明确「目前不用考虑多人模式」：P10单人首版/dev.16已实现，P10.2/dev.17已完成取得入口/原生闭环与显示收尾，当前顺序为人工单人试玩/定向平衡→B6与底部美术→候选版检查，R2/P10.1及新增多人专项暂缓。
- 保留历史最高等级 → 精力 → 攀爬 → 滑翔的已有循环，增加空中拉弓与林克时间。
- 新增近战、盾牌、弓三个背负视觉槽；真实物品仍在原库存，不增加容量。
- 温度以环境读数、HUD 和轻量表现为主；普通冷热不扣血、不减速、不增加精力费用。料理辅助原版细雪，耐热不等于抗火。
- HUD 按用户最新决定采用左上角红心、下方精力，底部保留原版经验条；滑翔双手、背负和拉弓共用明确的视觉占用规则。
- 单人真慢动作先经 R1 验证；多人局部时间另经 R2 验证，禁止一个玩家使全服减速。

## 执行顺序

| 阶段 | 交付重点 | 关键验收 |
| --- | --- | --- |
| R1 | 时间与呈现边界研究 | 真减速、正常瞄准、费用时钟、一次射箭、有限下降与完整撤销 |
| P3.1 | 背负装备 v0.1、左上角红心/精力、滑翔收纳（已完成） | 三类登记、无重复/幽灵物品、真实双客户端可见、原 P3 回归 |
| P3.2 | 单人林克时间 v0.1（本机完成） | 空中拉弓/耗尽/落地/退出完整；联机不启动全局减速 |
| 核心美术 v1 | 已接入交付的 14 编号美术，见 [接入](CORE-ART-INTEGRATION.md) / [验收](CORE-ART-VERIFICATION.md) | 新伞网格/双手与攀爬姿态、背负挂点/短动作、HUD/专注界面 |
| P4A | 环境温度（本机完成） | 群系/天气/水/热源、平滑和 HUD；普通冷热无新增惩罚 |
| P4B | 料理与细雪辅助（本机完成） | 烹饪闭环、有限保暖、耐热语义、精力效果、时长和旧数据 |
| P5 | 红石能源与有限电池（本机完成） | 信号与电量分离、固定无限能源限速、移动不无限供电 |
| P6（本机完成） | 机械主体、风扇/电池、吸附安装与拆卸回收 | 节点、物品所有权、满库存、重复和多人操作 |
| P7（本机完成） | 补齐八类机械部件 | 翼、风扇、火箭、电池、弹簧、轮子、稳定器、浮力装置的独立与组合行为 |
| P8（本机完成） | 古代装置制造机 | 输入/输出一次，中断恢复，结果保存，不反复抽取 |
| P9（本机完成） | 正式 Fuse | 宿主/材料、属性、耐久、附魔、维修、保存与模型分别验证 |
| P9.1（本机完成） | Fuse × 背负 × 林克时间 × 料理 | 同一物品一致外观、箭效果一次、费用增益一致 |
| R2（暂缓） | 多人局部时间研究，当前单人优先 | 作用集合、投射物归属、重叠、撤销、PvP 与性能边界 |
| P10（单人首版已实现） | 风与天气 | 自然水平风、避风、当地雨雪与滑翔/机械翼；不额外修改能源，见P10-SPEC/P10-VERIFICATION |
| P10.1（暂缓） | 多人林克时间 | R2 通过后开发；其他玩家正常控制，全局 Tick 不变 |
| P10.2（本批完成） | 单人取得入口、原生循环、轮子与HUD、数值基线 | dev.17见P10.2-VERIFICATION；人工手感、B6正式资源和底部外形另列待办 |
| P11 | 单人平衡、兼容与候选版 | 人工生存、性能、存档副本与安装检查；B6/底部美术接入后回归，公开发布另行授权 |

R1 未通过只阻塞 P3.2 的相关部分，P3.1 与 P4 可继续推进。R2 未通过则多人林克时间仍未完成，不能用滤镜冒充真实局部时间。P4A + P4B 才完成温度文档的首版全部要求。

## 保留与排除

红石能源、固定无限能源、有限电池、八类机械部件、吸附安装和回收、古代装置制造机、正式 Fuse、任意物品 Fuse 研究、风与天气均继续保留。R0 的研究成功不能直接认定正式系统完成。

继续不做：究极手、时间倒流、大型 Boss、完整神庙、大型新维度、复杂剧情、大量新矿石/资源体系、小型世界事件、环境谜题、机械蓝图。超复杂机械物理暂缓。不因温度新增饮水、普遍冷热伤害、机械过热或电池低温衰减。
