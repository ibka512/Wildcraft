按住G与现有攀爬权威资格、实际位置、ClimbVisual接入同一22蒙皮骨/真实原版皮肤；只选择空手、无盔甲/披风、默认实体缩放、平面碰撞墙的向上/左右/承重。源root固定，原生实体位移、库存、碰撞、攀爬费用与伤害保持。独立climb-down源缺失；下降、攀顶、拐角、盔甲/占手、其他复杂状态继续原程序。拐角改变壁面后，本次握持不重新切入新皮肤，松手再握才重新判断。GUI/真实使用/攻击/伤害/死亡/换维度退出互斥。

## 动作与时间

采用climb-up/v02（进入.30秒，循环实际向上位移/.43）、climb-side/v01（左右进入.30秒，循环实际沿墙位移/.32）、climb-idle/v01（最近方向的.30秒settle与3.3秒独立实际时间承重循环）。暂停冻结合法同状态时钟；原输入若释放握持，允许回原生，不为动画篡改输入。持键但实际被阻挡，不会靠持键时间推进循环；原ClimbVisual会由实际移动归零，选择承重。

旧ClimbVisual的3/4对应服务器墙切线负/正；实际A按键为正切线、D为负切线。新皮肤选择按实际按键与位移适配为left/right，保持旧网络码与物理行为，避免把源稿动作反向播放来掩盖编号差异。

头部显示yaw≤20°、pitch≤8°，只限制独立参考模型，不改玩家视线和镜头；身体面向实际壁面。其他持物/背负、原生皮肤外层可见性与C6F优先规则保留。

## 壁面接触

不能直接拿源稿wallPlaneY=-.34当游戏贴墙证明。源稿实际手掌/脚底承重点常为深度.290/.295；读取同源data.json的每帧contact target与planted标志，按GLB轴向转到共同坐标。按照原生AvatarRenderer的.9375缩放、LivingEntityRenderer的-1.501模型原点与现有BASIS计算实际点位。

实际墙面用原生COLLIDER形状射线定位，按承重点平均深度作有界的整个人物显示偏移（不移动实体、不改碰撞盒）。各已着墙点都须落在同一实际墙平面，超界、缺支撑或拐角转面回原程序。进入阶段未声明承重时不能冒称手脚已固定。循环仍由实体实际位移驱动，原数据接缝/滑步需要画面和实际数值检验，不能以元数据标签代替质量。
