# P3.2 单人林克时间实施规格

日期：2026-10-03。以当前用户确认的 Java/Fabric 方案及《林克时间开发文档》为依据，承接 R1 实测。此阶段不实现多人局部时间（R2）与 P4 料理温度。

## 玩家行为

- 未开放联机的单人存档中，生存玩家在空中实际拉弓、有精力时自动触发；没有新技能键。仅支持 BowItem 弓，弩照常使用，不触发本技能。
- 地面、持弓但未拉弓、零精力、旁观/创造飞行、鞘翅滑行、液体/游泳、骑乘/睡眠、漂浮/旋转攻击、攀爬按键或滑翔状态不触发。没有最低高度限制，自己搭的平台同样可用。
- 松弓、停止使用、落地、换掉实际使用的弓、精力耗尽、死亡、换维度、退出、暂停及开放 LAN 时退出。外部时间控制接管后退出，直到结束这次物品使用才允许重新进入。
- 沿用原版弓蓄力曲线、弹药、耐久、附魔与射箭路径；只有使用时长按有效实际时间补偿。不额外运行玩家或实体 tick，不自动瞄准，不新增伤害或暴击。
- 玩家有限缓降，保留累计摔落距离和原版碰撞/伤害；重复开关拉弓不会刷新悬浮额度或免摔落。攀爬和滑翔各自已有规则保持。

## 开发参数与时间控制

| 参数 | 开发默认值 | 含义 |
| --- | --- | --- |
| 世界速度 | 5 TPS | R1 验证过的真世界减速；退出恢复进入前实际速度 |
| 精力 | 10 / 有效实际秒 | 共用已有精力；暂停、离线不计费 |
| 单次时间差上限 | 250 ms | 长卡顿的超出部分舍弃，不一次扣巨额精力 |
| 等待期间输入轮询 | 最多 25 ms 间隔 | 只处理输入/计时，不多运行世界 tick |
| 下落速度限制 | -0.15 格 / 原版移动 tick | 只限制下降，保留重力、碰撞和摔落距离 |

这些是可调的开发参数，不宣称最终平衡。所有费用和蓄力真值由服务端单调时钟计算，客户端只预测弓的显示时长；不接受客户端秒数。最后松弓时补结算剩余时间。精力不足时只给已支付时间的蓄力补偿。

控制租约只适用于集成单人服务端、实际玩家数恰为一、未发布 LAN。入口拒绝冻结、步进、冲刺等控制状态。记录原速度和每次速率写入的版本；外部同值写入也会使租约失效，退出不覆盖对方设置。冻结模式与速度所有权分开处理，恢复己方速度时保留对方冻结。开放 LAN 在发布入口先恢复，独立服务端和 LAN 不减速也不扣本技能费用。

## 画面与设置

真正 GPU 去饱和，弱/标准/强分别 10% / 15% / 20%，少量冷色、青绿色边缘、轻暗角与准星增强；使用自写 GLSL 和原版后处理管线，不新增生产依赖。保留已有后处理列表，退出只移除本技能追加效果。

F8（可在原版按键设置中重绑）打开设置：总强度关闭/弱/标准/强；暗角、准星、边缘纹理、低精力轻闪、轻微视野收窄独立开关。纹理/轻闪/FOV 默认关闭，FOV 开启仅收窄 3%。轻闪仅低精力时约 0.8 Hz、极弱边缘提示。关闭效果保留技能、收费、精力 HUD 和进入/退出声音，不弹出打断瞄准的提示。第一/第三人称都适用，不强迫切换视角。

声音引用游戏自带紫水晶轻响，调整音高/音量；不复制游戏声音文件或使用任天堂素材。设置只保存在本机 `config/wildcraft-focus.json` schema 1，不写存档。现有玩家精力、装备、背负的持久化格式保持不变；技能状态、租约、计时、阻止当前使用记录都不保存。

## 验收

- 自动触发和所有退出条件；真正落地的摔落伤害；重复拉弓没有重置距离。
- 真实普通客户端测量世界/实体减速、拉弓实际时长、收费、鼠标更新、松弓延迟、弹药/耐久/附魔一次；受控图形测试不能单独证明实际时间手感。
- 租约恢复非 20 基线、重复退出、外部不同/同值写入、冻结/步进/冲刺拒绝；暂停不扣费，存档重开无残留。
- LAN 发布入口先恢复，独立服务端无控制和费用；滑翔取弓与攀爬冲突明确。
- 所有后处理变体真实 GPU 编译、第一/第三人称、总效果关闭和设置保存；旧 P0–P3.1 测试仍通过。

测试与人工观察的实际证据和限制写入 P3.2 验证报告，不能把实验通过冒称长期平衡完成。公开仓库当前发布为 dev.5；本阶段本机构建 dev.6，发布需单独明确授权。
