# C7 普通客户端水面浮力与载重核对

固定正式dev78，先做观察，不改原物理。独立复制生成测试世界，提供原API部件和1000电池，原绑定点击乘坐/R/前进/Shift下车；随身617电池不动。三种水池布景不是自然河流或人工从零获取：

- 1浮力＋电池＋风扇＋轮子：载客质量1.65，原单浮力容量1.75，预期保持水面。
- 1浮力＋电池＋风扇＋稳定器＋双轮：空载1.6尚浮，玩家上车后1.85超过容量，实际观察下沉，不把它自动当物理bug或强行补浮力。
- 2浮力＋电池＋风扇＋稳定器＋单轮：同样载客1.85，原容量3.5，预期恢复浮起。

记录真实preBoard质量/高度、上车后逐worldTick质量、浮力部件数、fluid height、位置/ground、载客和实际扣费。每个扣费沿原active部件，不强制固定费率：水里未着地轮子不收费，下沉触底后轮子可按原规则收费。R停机和下车后能量稳定，浮力是原被动效果，不用测试代码停重力、改速度或改电量。

先120FPS完整观察；如当前HUD没有解释载客后超载，只补已有机制的简短“浮力不足”提示，不加入新物理或质量资源系统。新提示要在同一个真实客户端绘制路径核对，baseline无提示不得冒称通过；添加前后固定生产JAR红/绿分开，实际风扇动力/浮力/载重守恒保持。低帧率和窄窗口按真实变化需要继续核对，失败保留，不把输入丢失/partial视为完成。
