# Wildcraft 战斗与统一输入系统设计文档 v0.2

## 1. 功能定位

Wildcraft 将重新设计 Minecraft 的玩家战斗操作与战斗逻辑，并将其建立在统一输入系统之上。

新的战斗体系围绕：

- 目标锁定
- 独立举盾
- 潜行
- 普通攻击
- 蓄力攻击
- 闪避
- 完美闪避
- 普通格挡
- 完美格挡
- 空中攻击
- 弓箭
- 林克时间
- Fuse

形成。

与此同时：

键盘、鼠标、Xbox、PlayStation、Nintendo、Steam Deck 等设备都通过统一的“动作层”控制这些系统。

---

# 2. 总体目标

Wildcraft 战斗系统不追求：

> 把 Minecraft 改造成魂类或传统第三人称动作游戏。

而是希望解决原版战斗的几个问题：

- 战斗方向感较弱
- 第三人称战斗体验有限
- 盾牌缺乏主动操作空间
- 潜行和防御语义混杂
- 武器区别偏数值化
- 高度和地形没有充分进入战斗
- 手柄缺乏原生完整操作体系

新的设计目标：

> 保留 Minecraft 简洁、开放的战斗基础，同时增加空间判断、防御时机、移动选择和武器个性。

---

# 3. 战斗核心结构

Wildcraft 战斗由三个主要方向组成：

```text
             攻击
            /    \
           /      \
        防御 —— 闪避
```

### 攻击

- 普通攻击
- 蓄力攻击
- 空中攻击
- 弓箭
- Fuse

### 防御

- 举盾
- 普通格挡
- 完美格挡

### 闪避

- 侧跳
- 后跳
- 完美闪避
- 短林克时间

---

# 4. 精力在战斗中的定位

普通行为不消耗精力。

例如：

- 普通攻击
- 普通移动
- 疾跑
- 普通跳跃
- 普通举盾

特殊高价值行为才消耗精力。

包括：

- 侧跳
- 后跳
- 林克时间
- 部分蓄力 / 特殊攻击
- 攀爬
- 滑翔

因此精力不是传统“耐力条”。

它代表：

**特殊行动资源。**

---

# 5. 统一动作层

游戏代码不得直接判断：

```text
玩家按下 Space
玩家按下 LT
```

而应判断：

```text
JUMP
ATTACK
DEFEND
DODGE
LOCK_TARGET
USE
SNEAK
```

硬件输入只负责映射到动作。

---

# 6. 输入架构

```text
键盘 / 鼠标 / 手柄
        ↓
物理输入
        ↓
设备映射
        ↓
输入上下文
        ↓
Wildcraft Action
        ↓
战斗 / 探索 / Minecraft 原版逻辑
```

---

# 7. 基础战斗动作

建议注册：

```text
ATTACK
DEFEND
DODGE
LOCK_TARGET
JUMP
SNEAK
USE
AIM
```

并根据当前状态产生不同结果。

---

# 8. 锁定目标

新增：

```text
LOCK_TARGET
```

玩家可选择两种模式。

### 按住锁定

```text
按住
→ 保持锁定

松开
→ 解除
```

### 切换锁定

```text
按一次
→ 锁定

再按一次
→ 解除
```

玩家可在设置中选择。

---

# 9. 自动目标选择

发动锁定时，根据权重搜索目标。

建议考虑：

1. 是否位于玩家视野内
2. 与准星中心距离
3. 世界距离
4. 是否正在攻击玩家
5. 是否属于敌对目标
6. 是否存在视线遮挡

大致优先：

```text
镜头中心附近敌人
>
正在威胁玩家的敌人
>
其他附近敌人
```

---

# 10. 不锁定无关生物

系统默认不应自动锁：

- 鸡
- 牛
- 羊
- 村民
- 宠物

除非玩家主动配置允许锁定中立 / 被动目标。

---

# 11. 目标丢失

满足以下情况解除：

- 距离过远
- 目标死亡
- 目标长时间完全不可见
- 玩家主动解除
- 玩家进入不兼容状态

短暂经过障碍不应瞬间解除。

---

# 12. 锁定后的移动

锁定改变玩家移动参考系。

```text
前
→ 接近目标

后
→ 拉开距离

左 / 右
→ 围绕目标横移
```

身体保持面向目标。

---

# 13. 锁定不等于自动瞄准

尤其对弓箭：

锁定只提供：

- 大致方向帮助
- 镜头目标保持
- 战斗空间信息

玩家仍然需要：

**自己精确瞄准。**

不加入自动命中。

---

# 14. 目标切换

锁定期间：

可通过：

- 鼠标快速移动
- 右摇杆方向拨动
- 独立切换动作

切换附近目标。

切换应优先选择当前目标左 / 右方向最近的合理敌人。

---

# 15. 防御与潜行分离

这是基础规则。

### SNEAK

负责：

- 下蹲
- 潜行
- 防跌落
- 安静移动

### DEFEND

负责：

- 举盾
- 格挡
- 完美格挡

两者完全独立。

---

# 16. 普通举盾

按住 DEFEND：

```text
玩家举盾
↓
进入防御状态
```

玩家仍可以：

- 移动
- 横移
- 后退

但根据平衡可能适当降低移动效率。

---

# 17. 普通格挡

敌人攻击命中盾牌有效范围：

```text
攻击
↓
盾牌承受
↓
减少或取消伤害
```

保留 Minecraft 原版盾牌核心价值。

---

# 18. 完美格挡

如果玩家在攻击命中前的短窗口内成功进入防御：

```text
精准举盾
↓
完美格挡
```

可能产生：

- 攻击完全格挡
- 敌人短暂硬直
- 轻微击退
- 投射物弹开

---

# 19. 完美格挡不是万能反弹

根据攻击类型区分。

例如：

### 普通僵尸

可造成明显硬直。

### 骷髅箭

可弹开。

### 大型攻击

可能只中断攻击或减轻冲击。

### 爆炸

通常不能执行标准完美格挡。

---

# 20. 闪避

新增逻辑动作：

```text
DODGE
```

在锁定状态下：

```text
左 / 右 + DODGE
→ 侧跳

后 + DODGE
→ 后跳
```

普通状态可以根据最终测试决定是否使用同样规则。

---

# 21. 为什么不做翻滚

Wildcraft 默认不采用翻滚。

原因：

- Minecraft 方块人体型不适合频繁翻滚
- 与方块地形容易产生视觉冲突
- 侧跳 / 后跳已经能提供空间战斗能力
- 更接近我们希望的战斗节奏

---

# 22. 闪避消耗精力

普通侧跳和后跳消耗少量精力。

防止：

```text
疯狂连续闪避
→ 无限无敌
```

---

# 23. 无敌帧

闪避可以拥有极短的有效避让窗口。

但不应成为：

> 按一下就能穿过所有伤害。

优先采用：

- 实际位移避开攻击
- 少量容错窗口

而不是大量无敌帧。

---

# 24. 完美闪避

如果敌人攻击即将命中时成功闪避：

```text
完美闪避
↓
短暂林克时间
```

---

# 25. 完美闪避林克时间

与空中弓箭林克时间不同。

### 空中弓箭林克时间

- 持续消耗精力
- 可维持较长时间
- 服务瞄准

### 完美闪避林克时间

- 持续很短
- 不持续额外耗能，或仅消耗闪避成本
- 服务反击

二者共用：

- 滤镜
- 时间视觉语言
- 声音语言

---

# 26. 普通攻击

点击 ATTACK：

执行当前武器的普通攻击。

不建立复杂连招树。

---

# 27. 武器类型

至少划分：

### 剑

- 快
- 稳定
- 恢复快

### 斧

- 慢
- 伤害 / 冲击高
- 恢复时间长

### 长柄

- 距离长
- 突刺能力强

### 重型

- 范围 / 击退突出
- 动作慢

### 弓

- 远程
- 与林克时间联动

---

# 28. 蓄力攻击

长按 ATTACK：

```text
按住
↓
蓄力
↓
松开
↓
强攻击
```

不同武器产生不同结果。

---

# 29. 剑蓄力

例如：

强力横斩。

适合：

- 多目标
- 击退
- 制造空间

---

# 30. 斧蓄力

例如：

高举重劈。

特点：

- 起手慢
- 冲击强
- 恢复慢

---

# 31. 长柄蓄力

例如：

强力突刺。

突出：

- 距离
- 方向性

---

# 32. 空中攻击

玩家处于空中：

```text
ATTACK
↓
空中攻击
```

近战武器使用独立动作。

---

# 33. 下落攻击

较高位置攻击：

可以形成强化下落攻击。

伤害随高度增加，但必须有上限。

---

# 34. 弓箭

弓箭保留 Minecraft 的基本逻辑：

```text
拉弓
↓
蓄力
↓
瞄准
↓
松箭
```

Wildcraft 主要强化：

- 动画
- 手柄瞄准
- 锁定辅助
- 林克时间
- Fuse 箭

---

# 35. 林克时间

默认：

```text
玩家处于空中
+
正在拉弓
+
精力 > 0
↓
自动进入
```

玩家也可以设置：

- 自动
- 手动确认
- 禁用

---

# 36. 林克时间不增加伤害

它只提供：

- 更多判断时间
- 更多瞄准时间
- 更清楚的战场观察

不直接提供：

- 伤害倍率
- 自动暴击
- 自动瞄准

---

# 37. Fuse 与战斗

Fuse 可以改变：

- 伤害性质
- 武器范围
- 击退
- 攻击速度
- 元素效果
- 箭矢行为
- 武器外观

但核心战斗动作仍由基础武器类别决定。

---

# 38. 怪物攻击必须具有可读性

完美闪避和完美格挡成立的前提：

> 玩家必须有机会看懂敌人在攻击。

因此需要改善部分怪物攻击前摇。

---

# 39. 怪物前摇

例如：

### 僵尸

```text
手臂后收
↓
向前挥击
```

### 蜘蛛

```text
身体压低
↓
扑击
```

### 铁傀儡

```text
明显蓄力
↓
上挑
```

---

# 40. 不把所有怪物变成 Boss

攻击前摇主要用于：

- 可读性
- 时机判断

不需要给所有怪物：

- 十种技能
- 大型血条
- 复杂阶段

保持 Minecraft 怪物的简单性。

---

# 41. 硬直系统

增加轻量硬直概念。

### 普通攻击

产生轻微受击反馈。

### 重攻击

产生更明显硬直。

### 大型生物

硬直抗性更强。

---

# 42. 不增加复杂韧性条

玩家不需要看到额外：

```text
Poise 73/100
```

硬直主要通过行为和动画表达。

---

# 43. 输入上下文

统一输入系统至少包括：

```text
GLOBAL
NORMAL
LOCKED_COMBAT
AIMING
CLIMBING
GLIDING
MECHANISM
RIDING
GUI
```

---

# 44. NORMAL

普通状态：

- 移动
- 跳跃
- 潜行
- 攻击
- 使用
- 锁定
- 背包

---

# 45. LOCKED_COMBAT

锁定战斗：

- 移动 → 环绕目标
- JUMP / DODGE → 闪避逻辑
- DEFEND → 举盾
- ATTACK → 武器攻击
- LOCK_TARGET → 解除 / 切换

---

# 46. AIMING

弓箭：

- 右摇杆 / 鼠标 → 精确瞄准
- AIM → 拉弓
- 林克时间按配置自动或手动发动

---

# 47. CLIMBING

攀爬：

- 方向 → 攀爬
- JUMP → 离墙 / 上跃
- SNEAK → 可根据测试承担下降等动作

---

# 48. GLIDING

滑翔：

- 移动输入 → 控制方向
- USE_PARAGLIDER → 收伞
- 其他动作可后续加入

---

# 49. MECHANISM

机械：

```text
MECHANISM_PRIMARY
MECHANISM_SECONDARY
MECHANISM_BRAKE
MECHANISM_DISMOUNT
```

根据机械类型解释。

---

# 50. 手柄默认战斗理念

建议类现代第三人称动作布局。

例如 Xbox：

```text
左摇杆
→ 移动

右摇杆
→ 镜头

右摇杆按下
→ 锁定

RT
→ 攻击

LT
→ 举盾 / 瞄准

A
→ 跳跃 / 上下文闪避

B
→ 潜行或其他可配置动作
```

这只是默认值。

玩家可以全部修改。

---

# 51. 举盾和瞄准的上下文复用

LT 可以合理复用。

### 手持盾牌

```text
LT
→ 举盾
```

### 手持弓

```text
LT
→ 瞄准 / 拉弓
```

这不是冲突。

因为属于不同装备上下文。

---

# 52. 玩家可以彻底重新绑定

任何默认键位都不是强制规则。

玩家可以：

```text
攻击
RT → X
```

或者：

```text
锁定
R3 → LB
```

---

# 53. 键鼠

键鼠同样走 Action 层。

不允许战斗代码直接依赖：

- 鼠标左键
- 鼠标右键
- Shift

---

# 54. 原版操作整合

原版行为同样尽可能映射为动作。

包括：

- JUMP
- SNEAK
- SPRINT
- ATTACK
- USE
- INVENTORY
- DROP
- SWAP_HAND
- HOTBAR

让手柄真正控制整个 Minecraft，而不是只控制 Wildcraft。

---

# 55. 上下文复用

同一个手柄按键在不同状态可以产生不同动作。

例如：

```text
A
```

普通：

```text
跳跃
```

锁定 + 横方向：

```text
侧跳
```

菜单：

```text
确认
```

---

# 56. 高频动作保持简单

不建议默认使用组合键控制：

- 攻击
- 举盾
- 闪避
- 跳跃
- 锁定

这些必须快速可靠。

---

# 57. 组合键

组合键适合：

- Fuse 管理
- 机械拆卸
- 低频特殊操作

例如：

```text
LB + X
→ 拆卸机械部件
```

---

# 58. 摇杆

完整支持：

- 移动死区
- 镜头死区
- 水平灵敏度
- 垂直灵敏度
- X / Y 反转
- 响应曲线

---

# 59. 瞄准灵敏度

独立提供：

```text
普通镜头
100%

弓箭瞄准
65%
```

具体默认数值通过测试调整。

---

# 60. 林克时间中的镜头

世界减速时：

**镜头绝不能同比例减速。**

鼠标和右摇杆保持正常响应。

---

# 61. 手柄震动

可以用于：

- 普通命中
- 完美格挡
- 完美闪避
- 拉满弓
- 林克时间进入 / 退出
- 重攻击
- 机械碰撞

不同事件使用不同强度和持续时间。

---

# 62. 完美格挡震动

推荐：

短、硬、明确。

让玩家不用看 UI 也知道成功。

---

# 63. 完美闪避反馈

同时使用：

- 动画定格
- 极短声音提示
- 轻微震动
- 林克时间视觉效果

但避免大字：

> PERFECT DODGE!

保持 Minecraft 风格。

---

# 64. 操作提示

所有 UI 禁止写死：

```text
按 E
```

应引用：

```text
INTERACT
DEFEND
LOCK_TARGET
DODGE
```

然后根据设备显示实际图标。

---

# 65. 动态设备提示

玩家使用鼠标：

```text
[鼠标右键] 举盾
```

随后使用 Xbox 手柄：

```text
[LT] 举盾
```

UI 自动变化。

---

# 66. 控制器图标

需要支持：

- 键盘
- 鼠标
- Xbox
- PlayStation
- Nintendo
- 通用手柄

---

# 67. 冲突检测

如果同一上下文出现：

```text
RT
→ 攻击

RT
→ 举盾
```

显示冲突警告。

不同上下文则允许复用。

# 68. 配置档

允许保存：

- 默认
- 键鼠
- Xbox
- PlayStation
- Steam Deck
- 自定义

等配置。

---

# 69. 锁定设置

提供：

```text
锁定方式：
按住 / 切换

自动选择范围：
近 / 标准 / 远

允许锁定中立生物：
开 / 关

镜头跟随强度：
低 / 标准 / 高
```

---

# 70. 闪避设置

可允许玩家选择：

```text
锁定状态：
跳跃键 + 方向
```

或者：

```text
独立闪避键
```

满足不同操作习惯。

---

# 71. 林克时间设置

提供：

```text
自动触发
手动触发
关闭
```

并允许配置滤镜强度。

---

# 72. 第一人称

第一人称完全支持新战斗。

不得要求玩家切第三人称才能：

- 锁定
- 闪避
- 举盾
- 完美格挡
- 林克时间

---

# 73. 第一人称锁定

镜头不能像第三人称那样强行吸附。

建议：

- 提供轻微目标方向辅助
- 玩家仍然控制准星
- 不自动把准星拉到敌人身上

避免晕眩。

---

# 74. 第三人称锁定

可以提供更明显的：

# 75. 多人模式

输入始终由客户端解析。

涉及战斗结果时：

```text
客户端
→ 请求动作

服务器
→ 验证状态
→ 执行命中 / 精力 / 闪避结果
```

不能完全相信客户端。

---

# 76. PVP

PVP 中：

- 锁定可以使用
- 举盾可以使用
- 普通闪避可以使用

但：

- 林克时间不能真正降低对方玩家时间
- 不能强制减慢对方操作

PVP 需要单独平衡。

# 77. 战斗与动画分离

战斗系统负责：

- 状态
- 判定
- 时机
- 伤害
- 精力

动画系统负责：

- 身体表现
- 姿态
- 过渡

两者通过事件联系。

---

# 78. 战斗与装备显示

切换武器：

```text
战斗系统
→ 更新当前武器

背负装备系统
→ 更新可见装备

动画系统
→ 播放拔出 / 收回
```

三个系统各司其职。

# 83. 最终设计定义

Wildcraft 的战斗与统一输入系统可以定义为：

> 在 Minecraft 原有攻击、盾牌、弓箭和自由移动基础上，引入目标锁定、独立防御、方向闪避、完美格挡、完美闪避、武器类别动作、蓄力与空中攻击，并通过统一 Action 输入层让键鼠和各种手柄自由映射这些行为。

核心不是增加更多按键。

而是：

**让 Minecraft 的战斗拥有空间、方向、时机与身体感，同时继续保持原版易于理解的操作基础。**
