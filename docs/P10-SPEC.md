# P10 单人风与天气首版

2026-10-06。用户授权下一批任务，且明确当前不考虑多人。基线 dev.15；先复核连续操作、料理/Fuse/专注、HUD 和机械路面，再实现本合同。R2 与 P10.1 暂缓，不增加生产依赖或真实存档迁移。

## 玩法

自然水平风缓慢改变方向和强度。首版在有天空、支持自然天气的维度生效；头顶处于原版阻挡高度以下时避风，水或岩浆中不施加风。只读取已加载当前位置区块，不模拟地形流体、乱流或上升气流。

- 装备伞并实际开伞后，原前后/侧向输入加水平风偏移。顺风更快、逆风更慢、侧风偏移；方向控制、专用装备位、双手占用与取物收伞保留。
- 风最大水平偏移 0.04 格/世界刻；基准滑翔仍向下 0.08。当地原生降水使下降最多额外 0.015，不能上升或取消收伞后的摔落伤害。原 0.34 水平位移检查不放宽，风不会增加精力费用。
- 装有机械翼、实际离地且不在水/岩浆的机械受到被动水平风力：每翼每刻风向加速度为风向量×0.05/总载重，合计倍率最多0.10。自然风与既有风扇、火箭推力合成，稳定器继续按实际供电抑制侧向漂移。
- 翼的下降判定改用相对空气的水平速度；现有0.12阈值、载重、重力和0.4水平上限保留。当地降水令翼下降上限额外增加最多0.015、水平速度最多再衰减1%。地面轮子和水中浮体保持现有规则。
- 晴天、雨雪和雷雨采用连续强度：最大风速0.016、0.028、0.040；实际方向/强度以两分钟一个锚点的平滑曲线变化，微阵风也平滑且始终有界。干燥群系能有强风，但无当地降水就不套用雨雪下降修正。
- 只在开伞或乘坐装翼机械时显示简短风向/风强提示；箭头相对视角表示风吹去的方向，避风状态清楚显示。沿用原版字体和程序符号，不把临时提示称为完成的B6美术。

首版不改变固定红石供电、有限电池、火箭燃料、弹簧冷却或温度读数；现有温度模块继续计算一次当地雨雪修正。雷雨只增强本阶段风场；雷击储能等未定稿能源玩法保留后续范围，不因本次阶段名称自动新增。

## 计算、同步与保存

逻辑侧依据世界种子、维度与gameTime计算风场。世界刻随暂停停止，单人林克时间降速时自然减速；不使用墙钟驱动玩法，不因离线补跑。种子和世界时间已有原版保存，风场不新增持久格式。

玩家仅接收本人当前位置的有限风视图：维度、水平向量、当地降水程度和室外标记。每5世界刻最多更新一次并量化，进入、复活和换维度重新计算；客户端滑翔读取该视图，不猜测私有种子。机械在逻辑侧计算运动，客户端继续使用原生实体追踪。死亡、退出或维度不匹配时不使用旧视图。

## 验收场景

1. 晴天顺/逆/侧风与无风对照：水平方向符合预期，始终下降，无位移检查误关伞。
2. 真实雨雪、雷雨、干燥群系和屋顶：强度连续、有界，当地降水判断与原版一致；屋内和水中无风作用。
3. 地面人物/轮子、水中浮体、固定红石源、电量、料理/温度不被风额外修改；风本身不支付或生成能量。
4. 机械翼无电仍被动响应，有载重、有风扇或供电稳定器时遵守原上限；未加载目的区块不扣资源或强制加载。
5. 攀爬→开伞→取物→空中拉弓→单人林克时间→落地；保持动作优先级、一次射箭和有效时间费用。
6. 多排心、三料理效果、缩放、隐藏HUD、第一/第三人称：风提示不盖准星、物品栏或已有读数。
7. 暂停、实际世界保存/重开、死亡/换维度、资源重载；风场确定性和临时视图清理正确。
