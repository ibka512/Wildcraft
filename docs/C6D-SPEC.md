# C6D：真实装备取出与收回的程序动作基础

基线dev.26，目标dev.27，2026-10-07。用户授权本批：近战五类、盾/弓/弩，第一/第三人称取收、打断兼容与本机验证交接。不新增生产依赖、持久格式、隐藏库存或美术采用编号，不上传GitHub。

只在同一非零会话引用由背(3)到真实手(1/2)、或由真实手到背时播放。初始快照、更换记录、消失、不同引用和直接双手转移不制造取收；普通热栏选择不登记实际使用。只读取已有三个视觉记录，不在绘制帧扫描库存。

近战取出0.34有效实际秒、收回0.38秒，盾/远程0.32秒。单次帧进度上限50ms；暂停冻结，离线清理。进入菜单、使用/挖掘、任一战斗动作、死亡/旁观/不可见、睡眠/激流、乘坐/游泳/鞘翅、攀爬/滑翔立即清理过渡并记录当前归属，结束互斥后不补播。动画不锁输入、不收费、不结算伤害，服务端归属不等动画。自定义准备/松开与按帧反击先调用原生已选槽位同步方法，确保换装与攻击意图的包顺序和原生携带槽缓存一致。

第三人称只覆盖真实相关手臂与微小躯干混合；头/腿保留原生。肩后与披风/鞘翅侧腰的手臂目标分别处理，原生盔甲消费同一遮罩。收回时只有空闲的原使用手回程；该手已拿到火把/新武器则保留新物品原生姿态。同一只手多条过渡优先取出，避免两次覆盖。

第一人称取出沿真实物品模型变换和握点显示实际皮肤臂，标准/纤细、袖子、左右主手；长矛/三叉戟/重锤只有空副手支撑。盾、弓、弩只使用其真实手。收回后不绘制已归属背部的出手副本，只显示空手回程；原生换装缓存尚持旧物品时抑制该手的旧提交，防止手/背重复，新物品正常接管。原生使用、地图、瞄准镜、滑翔等继续优先，实际物品组件不因渲染修改。

新玩家剪辑源稿仍未交付。这是可运行的程序过渡，不冒称完整取收美术或32项正式动画完成。第一批验收需原生按键/真实使用登记→真实归属→生产GPU提交、姿态/矩阵/袖子与副手、立即打断及旧回归。人工手感、外部资源包和真实硬件仍待验收。
