# C7 逐帧窗口条件校验

2026-10-15。仅修改独立gametest源集普通客户端探针与其任务参数，正式dev62 JAR不变。起因是持续运行虽然15场执行完，第二轮16主体末记录2090×1204，原来只保存末尺寸，无法拒绝测量中途变化；原始数据与限制完整保留，没有重写为固定条件通过。

探针现在逐帧记录实际像素与焦点状态。整次运行沿用第一场实际测量的像素尺寸，任一测量帧不同即输出failed、原始尺寸计数、焦点和partialScenes并退出；不把窗口变化后的帧率当成可比结果。焦点统计允许正常非最小化后台渲染，但原生限帧原因仍单独检查。

实际反例29秒：只在本次专用客户端测量开始1秒后调用原生Window.setWindowed(900,600)，真实像素由2560×1564变1800×1200；原生采样117帧旧尺寸、1帧新尺寸，立即被新校验拒绝，程序failed符合预期。没有调整个人游戏设置、原世界或正式mod，也没有用赋值伪造像素读数。反例开关默认false，只有-Pc7PerformanceViewportChangeProbe=true启用。
