# C4 攻击前摇与完美格挡合同

基线dev.21，实施版本dev.22。用户授权开始下一批，单人优先；生产依赖和存档格式保持，不上传GitHub。

僵尸/尸壳的原生MeleeAttackGoal在原版攻击资格满足后先准备10个世界刻，再复核同一目标、距离、视线和生存状态，调用一次原版攻击并进入6刻挥击表现；攻击后的原版20刻冷却保留，下一攻击仍需重新准备。目标离开/遮挡/更换/目标或攻击者死亡/原生目标停止会取消准备。保留原版寻路，不改其他僵尸变种/其他怪物，原版长柄专用SpearUseGoal不是本批的新前摇。原生导航提前完成时允许已经合格的前摇完成，不能使攻击绕过墙/范围。

完美格挡只由独立DEFEND从松开到按下的服务端新鲜意图开启，真实盾身份、兼容状态和盾冷却必须有效。窗口0–5刻（6个世界刻），最短重新开启间隔12刻；重复KEEP/重复同状态不刷新，菜单/换盾/使用/短跳/死亡/换维度/离线取消。一次按下最多一次成功，无新增精力费用或精力奖励。精确窗口内合格来源可即时使用真实盾，普通来源和长按盾保留原版生效延迟；方向、伤害减免、盾耐久、附魔与Fuse仍由一次原版applyItemBlocking路径结算，只有完整挡住才成功。破盾不额外奖励。

合格近战仅普通僵尸/尸壳MOB_ATTACK，完美成功造成12刻短硬直与轻微击退；C3真实蓄力命中这两种怪物造成8刻硬直。硬直暂停该原生近战目标的攻击/导航，有限时自动恢复；不增加玩家控制锁、复杂韧性条或全生物免伤规则。

投射物仅Mob射出的普通原版箭（非穿透/燃烧/药箭/Fuse箭），完整前方格挡后原生箭反弹环节执行一次真实方向反射，速度最高3，原箭归属转为防御玩家；不瞄准射手、不瞬移或复制箭、不增加伤害。箭仍由原版飞行、墙体、命中和捡起处理。玩家箭/PVP、药箭、火箭、大型生物、爆炸/魔法和其他来源继续普通原版规则，不授予标准完美格挡。锁定盾朝向仍用现有目标方向规则，自由镜头不获得自动命中。

窗口/前摇/硬直/反馈均按世界刻；世界慢时间同步变慢，不冒称C5真实时间反击。新状态/反射待处理不保存。客户端同步阶段只驱动怪物收臂/挥击/后仰、盾前顶、短声音/原生粒子/准星闪光；第一第三人称、左右手/两模型/盔甲保持，头部自由瞄准。没有新增正式美术采用ID。

验收：自然AI准备到实际伤害、墙/范围/换目标、单世界刻重复、前/后方向、窗口边界和普通盾延迟、持续/重放/重按/冷却/换盾、一次耐久/Fuse、真实箭碰撞/反射及来源排除、硬直恢复、真实键鼠改绑/菜单/死亡/维度、第一第三人称/模型/盔甲和既有攻击/侧后跳/弓/单人生存回归。人工战斗手感与实际手柄另列。
