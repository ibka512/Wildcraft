# P10.2 单人生存入口与表现收尾

2026-10-06，基线dev.16。本批使用专用世界验证合成→装备伞→料理→攀爬/滑翔/拉弓→Fuse→充电→组装驾驶→回收→制造补给。测试可以布置原版原料和场景，但成品必须通过原版合成/容器/安装操作取得；自动验收不冒称从零采矿或人工长期试玩。

1. 补齐原版配方书解锁：翼、轮子、火箭、弹簧、稳定器、浮力装置、制造机、空壳回收。取得相关原料后提示，旧解锁和配方成本不变。原版实测发现弹簧与指南针同图案，改用上下两对角铁锭＋中间红石（仍四铁一红石）；原十字图案保留指南针。
2. 料理锅内增加四类配方悬停指引，直接读现有七配方、强度和时长，中英文可读。空碗/火源说明与槽位不变，指引不替代服务端配方判定。
3. 降低侧面轮子显示挂点0.075格，补上其半径0.25与现节点中心0.325之间的接地间隙。预览与安装统一；不改变节点命中、主体盒、模型大小或轮子动力。
4. 复核乘坐视野和底部模型。底部部件外形伸出碰撞盒为已知边界，不用扩大碰撞、缩小原件或隐藏部件掩盖；交付实机和几何证据及后续美术修正约束。
5. 风HUD新增实际多排心、三料理、中英文、GUI缩放、隐藏与暂停验证；针对发现的遮挡作最小修正。正式B6资产仍由美术制作，本轮准备制作合同和验收清单。
6. 按当前代码测量精力与能源节奏。既定100+2×峰值成长和旧存档格式保留；没有体验证据时不盲改费率/容量，记录测量值、疑点及后续人工场景。
