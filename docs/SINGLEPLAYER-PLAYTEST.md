# 单人试玩流程与记录

P10.2自动流程使用原版原料、布置平台/墙面、站点间传送和经验样本；它验证真实物品与操作守恒，不等于从零采矿或人工手感。以下仍需在世界副本中人工完成，无需多人。

1. 新建普通单人生存世界，记录游戏版本、Mod版本、GUI缩放、峰值等级、当前精力；从正常采矿与原版资源获取开始，不用give/传送取得成品。记录找到铁、铜、红石、皮革和食材的实际时间。
2. 按配方书制作伞、锅、空电池、充电器与主体；确认弹簧按新图案产出弹簧、旧十字图案仍产出原版指南针。记录查找配方和首次操作困惑。
3. 料理锅悬停蔬/暖/凉/力，核对食材、碗、热源和效果时长；正常吃一份并确认碗返还。温度只反馈环境，不新增普遍冷热惩罚。
4. 在高度10、20、30格自然岩壁依次抓墙、放手、开伞、取弓、空中拉弓、射箭、落地。每次记录剩余精力、落地伤害、操作误触与HUD可读性；不要以无重力测试代替这项。
5. 用石头Fuse铁剑，实际攻击并记录材料扣除、次数、背负和保存重开；不要求未知材料都具有专属特效。
6. 固定红石块旁充电器充电，安装双轮进行50格/100格平路驾驶，再测试风扇＋稳定器组合。记录距离、满电持续时间、启停和拆卸难度；停止后回收，核对余量。补测原版1格台阶、高墙与水面。
7. 制造机每次投入4铜＋2红石，取得补给，移动已停设备并保存退出；重开核对峰值、伞槽、电池、料理剩余时间、Fuse和制造结果，没有重抽或免费回满。
8. 晴天/雷雨、露天/屋顶、开伞/翼骑乘；观察相对风向、下降和读数。切GUI1/2/3、中英文、F1、暂停，检查红心→精力→温度→料理→风提示、准星及底部栏。

记录格式：场景、原料获取时间、目标距离、峰值/初始精力、前后电量、失败原因、截图、主观说明。将“操作问题”“数值问题”“视觉问题”写明实际触发条件。底部弹簧/浮力等越出单主体碰撞盒为已知表现边界，不能据此断言复杂机械物理已完成。

只有人工记录支撑后，才为下一批提出具体费率调整；涉及成长、容量或其它显著玩法改变按已有用户授权范围决定。候选版、GitHub更新及公开发布单独执行，不把本机测试通过写成已经发布。
