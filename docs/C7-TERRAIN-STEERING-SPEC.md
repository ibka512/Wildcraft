# C7 受控地形与转向普通客户端验证

接续本机正式dev76。只新增隔离gametest源集的普通客户端观察器/布景与可选任务开关；生产JAR固定dev76，依赖、库存、持久化、物理、费用和原生计时不变。不是新复杂机械物理，也不是人工自然地形或从零获取验收。

先完成旧驾驶逐帧窗口guard的10FPS运行，保存实际JSON/日志/6PNG与源码/执行包SHA。旧无guard的10FPS结果不替代新检查，不重跑稳定full48/125。

随后新建独立可弃世界副本，用原API提供1000电池和两个原轮子，随身617电池保持，真实绑定点击队列乘坐/R/前后左右/Shift下车。不对运行中机械的位置、速度、朝向或电量赋值；准备场景的初始布景/出生位置与运行中的原生运动分开。

四场景：

1. 平地前进并左转/右转，观察真实输入、原每刻3度转向和水平轨迹。
2. 平地倒车，观察原倒向推力、付费及实际负向位移。
3. 直行碰整方块墙，验证不穿墙，记录阻挡时原始耗电，不为测试暂停扣费或改速度。
4. 驶下一个整方块落差，验证实际离地/下降/重新着地与继续行驶，记录空中轮子停止付费的真实变化；不引入自动爬坡。

每个实际服务端刻只读记录实际乘坐/输入、worldTick、位置/朝向、onground/碰撞、active轮子和电量，检查每次扣费沿原active部件费用且初始电量减余量等于真实扣费总量。每个客户端采样帧记录实际像素，整个运行固定同一尺寸，原生限帧原因NONE；丢焦点或输入释放应拒绝结果而非伪造连续输入。120/10FPS分组运行，只在实际完整终态后记通过。

每场停止输入、原生R停机、Shift下车，再核电池/部件/随身电池不变和不持续扣费。截图、原始刻记录、源码与执行JAR指纹均本机留存；实际源资格/自动布景不能冒称全部机械或长期性能通过。失败先保留与最小定位，不改生产物理迎合断言。

不新增生产依赖、不迁移真实存档、不上传GitHub，不采用待审素材。其他四美术WD/untracked与历史证据保持。开始/定期核额度，任一窗口余量≤5%只保存，按实际reset+一分钟续调且不用券。
