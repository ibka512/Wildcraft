# Fuse v1 可替换表现原型

当前复用宿主与材料的原版当前物品模型，不复制Minecraft图像或为每种组合注册物品。FusionItemRenderer按真实宿主显示上下文添加一个有界材料模型，原版GUI、双手、掉落和背负共用。剑/斧/箭的挂点为(.77,.78,.53)，盾中心(.5,.5,.34)；材料按其模型包围盒归一到.32。实际飞行箭单独归一到.22并挂在尖端.35。

入口在src/client/.../fuse；轮廓、握持和体积仍属首版原型。外观只依据material ID/kind/uses/glint，不读取私人容器、名称或自定义数据；未知模型回退屏障图标。复杂第三方自定义渲染仍须专项验证，不能由原版截图承诺全面兼容。
