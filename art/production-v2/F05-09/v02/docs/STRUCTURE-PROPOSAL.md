## 结构方案

底节点在主体底中心(0,0,0)，本地+Z安装后朝下。原浮力装置包围X±0.32、Y±0.20、Z0.02..0.40格，底装落地时最低点−0.40。它没有独立碰撞盒，不能依靠浮体自己垫高主体。

本方案保留15件原尺寸网格、94个面、原UV、浅色倒角浮体、中央铜色束带、钢扣与安装板。底部专用网格仅在本地z整体偏移−0.41格，尺度1.00。压缩、充气、展开、伸缩和active动画均不新增；浮体固定放在凹舱里，地面与水中工作保持同一外形。

候选本地包围为[−0.32,−0.20,−0.39]到[+0.32,+0.20,−0.01]格。直立且主体底中心y=0时，浮体世界最低点+0.01、最高点+0.39。活动组数量0，轴心为原节点，位移上界0。偏移是安装外形适配，不改变节点位置、眼射线命中或安装许可。

主体配套凹舱开口0.69×0.45格、深0.41，浮体每侧净空0.025、顶部净空0.02。原底座和主体核心实际拆成包围凹舱的实体块，上方盖板和其他节点细节保持；底节点旧装饰面板由开口与四边浅边框替代。边框位于开口外，y=0.01..0.04。71个配套主体网格单独保存，不覆写原F05-01。

弹簧方案的凹舱宽0.4875，小于浮体宽0.64，不能直接套用。两个主体显示变体只在底节点分别为弹簧或浮力装置时选用；原游戏同一节点只能安装一个部件，不增加新的装配槽。安装预览也需要使用与候选部件匹配的主体显示变体，尚未实现。

“前半剖开”仅是观察内部的审稿功能。完整源模型没有隐藏浮体，凹舱是真实空缺；另有“底部开口仰视”视图，在关闭剖开后从下方查看浅色浮体和铜带，地面平面仅在该审稿视图关闭。浮体不进入生产时隐藏名单。碰撞仍为1.4×0.65格原主体盒，凹舱不创建玩家能进入的物理空间。

其他五个方向继续使用原v01浮体与原主体；本包只有底装专用改动。侧装、顶装快捷场景和20组其他方向一致检查已经保存。其他方向原主体的旧边框少量越界不属于本项修订，净空指标明确只指浮体。

## 水中状态与现有规则

现代码`MachineEntity`计算：`mass = 1 + .1 * installedParts + .25 * passengers`；`floats > 0 && machineWaterHeight > 0 && mass <= 1.75 * floats`时，增加Y速度`.07 * floats / mass * min(1, machineWaterHeight / .4)`，该段Y速度上限.15。

整机关闭、没有电池或电量为0，不取消这个被动水中条件。空气、岩浆、没有有效WATER高度和超载不提供浮力。浮体工作状态的active来自服务器节点位，不增加工作灯、纹理切换或自动充气。实际移动还受重力、碰撞与目的区块是否加载等现有条件影响，网页参考公式不代表某一刻提交后的真实速度。

浮力来源是主体有效WATER高度，不按本候选浮体浸水面积或体积重新计算。凹舱内浮体被水线覆盖是装配观察，不建立新的密封舱、空气袋、排水量或真实船体物理。

网页示例：1件浮力、3个已安装部件、1乘员，mass=1.55，容量1.75；示意有效WATER高度.25，可提供约.0282258格/刻的参考速度增量。改成6部件、1乘员时mass=1.85，超过1件容量，参考浮力为0；模型外形保持相同。数量参数仅用于规则阅读，画面只画所选节点的一件浮体，其余部件不在场景中渲染。

水面y与主体有效WATER高度是分别标注的示意/参考参数，不预测静止平衡水位、总浸水体积或真实客户端采样。空气与岩浆场景的有效WATER参考高度归零。安装预览只检查候选外形和统一幽灵色，不把预览件计为有浮力；安装预览时隐藏参考载重/容量数值，不尝试用这一张审稿快照模拟其他真实已安装部件的浮力。

## 侧倾与地面边界

现`MachineRenderer`在onGround时roll=0，空中未稳定时最多±6°。本包地面默认0°；另保存离地0.20格、±6°的网格验证与空中侧倾快捷场景，没有擅自调整渲染滚转规则。

若人为设置主体底中心0、地面0并保留6°侧倾，浮体最低点约−0.00361345，预览会显示这一边界。它不是当前原生落地姿态，不能用离地侧倾通过推断真实落地插值绝无穿插。客户端实际落地切换、台阶、斜坡、方块形状、水下透明排序和乘坐视野仍需后续接入验收；没有添加净空采样、碰撞、额外浮沉或动态位置修正。
