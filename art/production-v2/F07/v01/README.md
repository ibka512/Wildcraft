## 本次交付

方向箭头表示风吹向哪里，按玩家视线：前↑、右→、后↓、左←及四斜向，不表示来风。一/二/三缕风线表示轻/中/强档；轻档包含接近无风，不新增独立无风状态。遮蔽组件替代方向与强度，湿润可作为独立附注。图集内没有固定文字、数值或按键。

## 状态与排布契约

仅开伞或乘坐带翼机械显示，地面行走隐藏。风强度按水平速度：小于0.012格/刻轻，小于0.024中，其余强；降水大于0.2显示湿润。实际本机屋顶、水中、无天气维度采样是遮蔽且降水为0，所以这些场景不亮湿润水滴。虽然组件允许遮蔽/湿润组合，预览不虚构屋内仍在下雨。晴天使用0.006/0.014示例，不提供强风；雨雪强风示例0.026，均在当前上限范围内。

候选风行高20逻辑像素，置于温度及已能显示的料理效果下方，包含2像素上下留边。方向和强度相隔4像素；附动态文字及湿润图标。优先完整排布；文字导致空间不足时改为紧凑图标排布；仍不足则隐藏整行，不占用中心20×20准星安全区或底部46像素区域。料理布局复现当前规则，不为了显示风而强行挤入或重排旧HUD。

当前游戏临时字体风行高约12像素；本候选20像素的图标行和紧凑策略属于待接入排布建议，未改变生产界面。浏览器字体近似，真正游戏字体测宽、实际缩放和运行状态仍需采用后验证。

湿润只解释已有规则：有效雨雪使伞下降略快、翼阻力略增。伞/翼的模型、纹理和原版雨雪继续复用。本包不新增伞布动画、上升气流、雷击发电、雨天攀爬打滑、全屏Shader、声音或运行粒子。
