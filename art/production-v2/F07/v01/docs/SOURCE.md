# 来源与复用

13个组件由本机逐像素设计，通过Aseprite Web的typed CLI绘制、分层、保存和导出。没有高分辨率图直接缩小或AI图像减色。箭头、风线、屋檐、水滴采用通用几何表达，没有临摹其他游戏专属标志。

references中温度、料理、精力PNG来自本工程已采用资产，源路径和哈希见DEPENDENCIES.json，原件未修改。预览背景、红心、准星和底栏为原创位置示意，不复制原版游戏文件。天气结构图仅表达已有伞翼响应，不替代采用模型。

Aseprite Web、浏览器和Python图像读取为既有本机制作工具，不增加模组运行依赖。PNG单组件从原生图集按格提取，像素不重新设计。无需额外制作24张完整风HUD面板；动态文字和状态组合由后续运行绘制。
