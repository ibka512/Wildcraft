# S01 真实事件与播放接入边界

本文件是后续接入规范。本轮仅制作音效与独立审稿播放器，没有修改Java、sounds.json、语言、网络协议、存储或正式JAR。

详细12项见exports/event-map.csv。CookingPotEntity的progress/status与ChargerEntity的余量/status是菜单数据，并不能据此假定世界范围声音事件已经同步。FabricatorEntity同样只提供任务与菜单进度。接入应在服务端事务成功时单次发出声音或确认事件；客户端不能解析提示文字、按键、VIEW组件或读取第一帧状态来推测成功。

1. 料理：新批次首次有效进度0→1报开始；失去热源后恢复同批次不重播。已有进度读档不报开始。输出和材料扣除提交后报完成，取成品不再响。
2. 充电：当前插入电池第一次真实注入才报开始。轮流供电产生的零分配不重置会话；原已满电池不报充满。比较同一次注入前后真实电量，跨容量才报满；若同一次事务开始并达到满电，仅报满。电池无稳定身份时不能依赖ItemStack对象引用跨载入辨认会话，需接入时明确插槽会话或服务端瞬时事务标记；本轮未改存档格式。
3. 安装/拆卸：MachineEntity.install/recover返回true且物品转移已提交之后播放。拒绝操作、透明预览、运行中不能拆、背包满等无成功音。主体回收沿用原版行为，火箭燃尽与弹簧弹射暂不新增音。
4. 机械启停：enabled开关不等于有动力。读取有效事务提交后的ACTIVE，仅提取kind 1/6/7供能风扇/轮子/稳定器；被动翼/浮体、火箭和单刻弹簧不归入通用轴声。正常起动连续2世界刻确认，动力消失连续4刻确认，启停提示同实体间隔12刻；明确关机可立即确认，但已停不重复响。去抖按世界刻，音频播放按客户端真实时间。客户端首次见到实体、卸载/重新载入不播放启停提示。
5. 制造：FabricatorEntity.start成功后报开始。进度100且输出槽空，pending真正写入items[2]并清空后才报完成；堵塞时不预报，读档已有输出不报。
6. Fuse：FusionActions.fuse/split成功后的服务端确认，分别与F03-04内收/外散反馈共享同一事件序号。失败与重复确认没有成功音。

优先级：玩家安装/拆卸和Fuse为4，完成为3，后台开始/停止为2。同来源最多1声、同事件全场最多2声、全场最多6声，优先替换低优先级/较早声，否则裁掉额外声音；不延迟排队补播。source需包含维度与实体/方块身份，operation需单调序号或确认UUID并带连接epoch，避免重连误去重。审稿参考缓存TTL5秒、256项；游戏是否直接服务端广播或客户端共用预算需接入时确定，不能把审稿JS直接当Java实现。

短声loop=false、stream=false，建议pitch=1.0；安装/拆卸可在0.97–1.03小幅变化，复用同母带避免重做。游戏音量0.22–0.30、参考最大距离6–12格，详见playback-spec.json。单声道留给Minecraft做空间定位。试听页线性距离衰减是比较工具，不宣称与实际游戏声场完全一致。

停机后没有循环音；移除来源、卸载区块、退出世界时停止来源声音并清理缓存，暂停行为沿用游戏声音管理器。不会为卸载播放“停止工作”提示。F03-04原版火/冰/弹性命中继续借用对应原版动作及效果声音，本项不叠新命中提示音。

exports/sounds-additions-proposal.json只有12个新增事件建议，不能覆盖运行中的sounds.json。接入时将exports/sounds/*.ogg放入assets/wildcraft/sounds/s01/并合并事件；字幕建议单独提供中英文，真实语言资源本轮保持。沿用现有原版字体与音量设置，不新增生产依赖。
