# A09-C 后续接入边界

本轮只交付美术位置与参考工程，正式游戏未使用此布局。

## 尺寸与变换

继续使用真实、已净化的ItemStackRenderState模型；按实际FIXED模型边界取中心。五类位置是可视中心目标，属于身体局部坐标，不是冻结的世界坐标。原版盾FIXED已有0.55比例，层级需补偿1/0.55；剑/斧层比例0.85，弓/弩0.90。有效腰侧/手持比为1.00；不重复对宿主或融合材料缩放。

waist-layout.json明确设计坐标、旋转顺序和身体挂点。Java坐标Y向下；原渲染器还先转Y轴180度，原版显示上下文自身有变换，因此设计roll/yaw不能直接抄入Axis调用。javaBodyLocalCenterUnits仅换算视觉目标，实际层变换应补偿已提取模型边界中心，并在原版绘制顺序下验证。第三方改写FIXED变换时，不盲用默认盾补偿。

蹲姿补偿是身体局部上移：剑1.1、盾4.1、弩0.3单位，不缩模型、改碰撞或抬人物。躯干的实际setupAnim变换每帧驱动位置；站/蹲/游泳/滑翔参考不能代替完整动画连续采样。标准与细手臂共用装备尺寸，角色皮肤及袖层仍使用原版。

无实际披风或鞘翅时，继续原A09背部挂点；没有“第四套物品”或重复影子。检测实际可见披风，而不是只检测账号存在披风纹理。鞘翅同时占用背部时沿用原版实际披风可见性条件，不在自定义层强行多画一件披风；审稿both场景以鞘翅优先代理示意，需在游戏验证原版条件。

## 三类真实引用

当前BackEquipment.publish在玩家穿鞘翅时，先把盾和远程显示堆栈过滤掉；当前BackEquipmentLayer.extract又在披风显示时隐藏整层。因此后续接入仅修改客户端挂点不够，必须在既有白名单和真实归属逻辑下，保留可由客户端择位的三类展示数据，并更新层的披风/鞘翅策略。该变化未在本轮实施；不新增真实库存槽、保存引用或私有组件。

同一真实引用在手上显示时，腰侧不再画；相同外观的备用物品不移除原登记引用。拉弓时按现有盾收起规则继续处理；双手滑翔持伞时，符合登记条件的三类装备可显示。第一人称本人、隐身、旁观、死亡、丢弃、损坏与引用失效保持既有隐藏/即时移除规则，不使用名字或物品ID推断身份。

布局切换（披风/鞘翅出现或消失）只移动现有显示物，不算新使用登记；旧挂点与新挂点不能同时画。攻击、取物、举盾和拉弓立即遵从实际手持状态，不等动作播放完。后续处理换装和身体姿态过渡时需确认连续性，不能把本版四张静态姿态认作完整动作衔接已完成。

## 短落定与融合

腰侧采用0.15–0.30单位的小幅偏移，近战180ms、盾/远程200ms，偏移权重沿用(1-t)^3；无缩放或额外伸手。不要把原A10背部的0.6–1.6单位偏移直接套入更紧的侧腰区域。改动只针对腰侧后续局部落定，原手部即时动作和第一人称装备动画保持。

融合材料位置、方向和上限来自已采用F03-01，随宿主整体变换；审稿只用石头上限立方体检查占用。未知材料回退、真实材质和附魔继续已有方案；本轮不扩展弓/弩Fuse宿主。大型异常或第三方动态模型需独立验证，优先在保持物品尺度的前提下重新择位；无法保证时可按已有策略隐藏冲突显示，不能用大幅缩小掩盖问题。

## 待游戏验证

验证原版实际披风可见性、鞘翅开合、行走/奔跑/蹲下/游泳/伞握持与落定中间帧、盾纹和光泽、真实三引用切换、两个普通客户端、标准/细手臂、主副手与左手主手、视角缩放及特殊模型。原版盔甲与袖层还需实际渲染检查；静态代理的表面检查不能保证真实动画或第三方装备兼容。
