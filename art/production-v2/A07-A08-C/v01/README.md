| 复核场景 | 处理要点 |
| --- | --- |
| 攀爬→开伞 | 从当前呈现姿态进入，300ms到采用握持；伞即时显示 |
| 抓墙→空手放开 | 原放手全片段映射到200ms，结束对齐当下原版姿态 |
| 上攀→横移 | 120ms局部接续；移动相位仍由实际位移驱动 |
| 持伞→空手收伞 | 伞即时消失；200ms空手回落 |
| 持伞→取剑 | 清空持伞覆盖，原版持物立即接管；只保留原140ms物件落定 |
| 持伞→拉弓/举盾 | 即时交给原版双手动作，不做自定义手部落定 |
| 快速收伞→重开→拉弓 | 从最新呈现姿态重新接续；拉弓直接打断 |
| 登顶→站立 | 只恢复肢体，不加实体根运动或新的翻越能力 |
| 状态失效 | 即时移除伞/物件并清空参考，不播滞留退出 |
| 上攀→停住 | 无位移不继续循环，转抓墙参考 |
| 持伞→相同备用剑 | 备用剑与登记剑是两份不同引用，不误隐藏登记剑 |

当前代码只播放放手片段的0～6帧，原稿为0～18帧；两种手臂在4→5帧有约353°的原始Euler跨界。修订采样采用归一化四元数短路径插值，复用原动作关键姿态；不用加快游戏、加动作锁或绕一圈来掩盖问题。空手出口与入伞开始也对齐当前呈现姿态。
