# A07-A08-C 后续接入说明

本项是美术与呈现规范。正式CharacterPoses、GliderHands、BackTransitions及游戏状态均未修改。

## 当前证据与拟修订范围

CharacterPoses在setupAnim末尾覆盖四肢；开伞直接使用glide片段0～9，达到稳态用300ms。攀爬片段由真实位移×18驱动，切片段重新计相位。放手仅在空手、未使用物品且存活时执行200ms，但elapsed×30只取原release的0～6帧；原片段总共19帧。当前逐分量Euler插值穿过±π时会走长弧。本机两套release4→5帧有约353°数值跨界，不能把这理解成设计了完整转臂。

三种局部修订分别为：300ms入伞以当前呈现姿态接入原glide采样；200ms空手放手使用完整release并在尾段交还当下原版姿态；120ms攀爬片段接续。空手收伞与登顶结束直接从呈现姿态回原版，不强制重播抓墙release。所有肢体位置线性插值，旋转采用归一化四元数短路径SLERP，接续权重smoothstep。原源稿与原运行烘焙文件保持，接入时再按实际需求实现，不直接替换为审稿测试数据。

## 优先级与中断

真实动作/持物状态先于自定义肢体覆盖。攻击、使用、拉弓、挡格和失去引用直接清除相应自定义覆盖；接管当帧使用原版setupAnim与物品层，不等退出或落定。攀爬时取物亦不得让自定义手臂盖过原版使用；此规范只规定呈现，不新增边攀爬边操作的玩法许可或改变服务端攀爬状态。

空手放手是唯一可以保留短肢体回落的普通退出。若回落中取用物品，立即交还使用双手。重开伞时从最新呈现姿态取快照，而不是旧起点；同帧的最终权威状态只产生一个呈现结果。快照是局部骨骼变换，不缓存共享PlayerModel可变对象或上一帧世界矩阵。每帧先取得原版setupAnim，再施加允许的覆盖，结束后不遗留旋转。

死亡、隐身、旁观、断开、重生、维度切换清空过渡记录；暂停不积累可重播的动作。弱引用、清理时机和本机有效时间应沿用项目约定，不新增通用动画依赖。移动/阻挡循环依据实际位移，不依据按键持续时间；审稿时钟不能抄进玩法作为攀爬速度。墙面方向、转角和实际相机自由度在游戏验证，本审稿同墙上攀→横移不模拟墙角旋转。

## 装备、短落定与第一人称

A09-C已采用的五类挂点与尺度保持。手部/背部归属依据原有真实引用，先移除旧归属，后在新归属上短落定。相同外观备用剑是另一份引用，允许备用剑在手与登记剑背负同时存在。不得用物品ID、名字或外观去重，不新增库存格或从视觉复制真实物品。

140～200ms落定继续A10规范：攻击/使用/拉弓/挡格时取消手部落定；腰侧只用A09-C的小偏移。没有连续手到背的抛物轨迹，也没有伸手拿回伞的新增动作。伞层显隐随实际Gliding状态即时处理；本项不制作缩放伞面或新折叠模型。融合材料跟随宿主，保持F03-01上限与A09-C尺度，不独立缩小。

当前第一人称GliderHands使用GliderPose稳态，而第三人称使用入伞片段。审稿保留这种有意区别，避免为了等第三人称伸手而延迟第一人称持伞或修改镜头。持伞时清空原版主副手物件；取物时先清空自定义双手/伞框，恢复原版手部选择与物件。第一人称仍保留原版equip/swing动画，不加入自制跨屏收取。70°垂直视场和16:9是既有参考，其他宽高比/FOV/左主手/袖层必须实机核对。

## 验证与限制

审稿场景固定躯干，不烘焙EntityTrajectory_PREVIEW_ONLY的根运动；实际攀爬、登顶、下落和碰撞由现有玩法处理。原版参考肢体在头部零角、站姿下取样，不包含完整行走、受伤、看向和物品显示上下文。手持模型使用原轮廓与有效比例，其挂点为可见占用引导，不能直接作为原版ItemInHandLayer替代。用户审稿通过也不代表这些原版组合的游戏验证已经完成。
