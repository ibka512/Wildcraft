# 接入映射（本轮只交付美术）

基线：Fabric Java／MC26.3／dev.14，FusionPresentation 当前只在ItemTooltipCallback追加实际材料、剩余次数、类别、不可用ID和当前融合键说明；当前游戏没有本版的槽位角标。本轮不修改正式客户端或资源。

槽位：ItemStack含有效FusionContent.VIEW时读取材质ID/kind/uses/glint的公开外观记录。kind0～6共用角标；6表示记录尚在但效果停用，提示必须保留停用文字，不伪装成正常元素效果。普通物品／空槽／组件移除时角标不绘制。实际箭的融合要求单件，不制作“融合箭×64”的伪状态。

在原版物品、光泽、数量及耐久绘制后加入独立角标，使用本版64×32图集中的5×5区域，保持原GUI整数缩放。仅使用原槽内容坐标关联，不依赖屏幕像素固定位置；物品栏、容器、快捷栏及独立展示上下文需逐一核对。自定义大模型进入左上区域时，可兼容适配为仅悬停显示完整符号，避免逐帧读取GPU像素或扫描私有组件。

角标[0,0,5,5]与18×18槽位一致；原物品[1,1,16,16]、数量右下、原版13×2耐久条保留。预览中的5×7数字是布局参考，正式接入调用原版字体／数量层。计数不复用item count、不改耐久条、不新增第二条磨损条、不烘焙进贴图。

悬停：16×16符号作为“已融合”或不可用“融合记录”的分组标题；精确行继续使用当前fuse.wildcraft.tooltip，保留类别／不可用ID／控制说明。uses只读FusionVisual.uses，范围1～32。最后4次采用琥珀文字，最后1次明确提醒；这是表现阈值，不改消费或玩法。控制说明使用当前绑定键和当前潜行逻辑，网页V仅为默认键示意。

耗尽时按服务端已有逻辑移除DATA与VIEW，客户端随实际组件同步撤掉附着模型／角标／次数；不得建立有效uses=0的视图，不预测消费、不倒计时、不复制堆栈。保留原宿主、耐久、数量、附魔和名称。

拆分后真实材料有FusionContent.WEAR时，在材料说明中显示保留次数，不加已融合角标。该说明目前未接入，需要后续补对应原版可翻译文案及范围校验；不读取原始材料私有快照。缺失WEAR时默认完整次数由原玩法确定，本版不额外添加新状态。

不可用材料回退本轮只复核文字；仍沿用当前安全路径，F03-03再制作中性外观。第三方特殊模型、原版药水箭／光灵箭、绑定键修改、多语言长名称、重叠槽装饰和各界面需真实游戏验证。
