# 接入说明 · F05-02 v01

本目录是美术交付，未写入游戏。`wing-geometry.json`为显式顶点/面UV，坐标单位1/16方块。Blockbench为free mesh可编辑源稿，不能把它直接复制成Minecraft方块模型。

接入时仅替换MachineRenderer的kind=3原型翼面。零点就是现有节点；按MachineNodes既有六向基底旋转后加节点位置，再沿用整机旋转。不缩放、不再追加旋转、不改变安装或物理状态。根部铜触点Z0.60至0.64为刻意向内接触段。布面是固定薄棱柱，木架和根部也固定。

统一图集128×64：左64×64完整机械图集；右上cream(64,0,32,32)、olive(96,0,32,32)，右下wood(64,32,32,32)、cloth_back(96,32,32,32)。几何JSON的U/V分别归一到0..16，转像素时U×8、V×4；Blender采样U/16与1−V/16。旧机械/风扇UV若临时绑定到此图集，仅U减半；不能把新UV误按64×64处理。最近邻采样，不启用平滑纹理插值或新Shader。

物品16px图为第一版常用尺寸，32px为高分辨率备用；二者有独立三层Aseprite源稿。资源路径继续对应现有wing物品注册，接入时遵守当前资源布局；本轮没有改物品注册和资源文件。

被动翼不消耗电量，不要求电池或整机启用。当前服务器按翼数、向下速度和水平速度标记每个翼节点active，整机working只描述实际供电或火箭燃烧。不得把enabled、working、电池余量当作翼生效开关。HUD若提示「滑翔起效」，读取kind=3节点active；翼模型始终静止，不增加发光/扇动/升力特效。

安装幽灵使用同一实际网格、尺度和节点方向。F05-10采用版的全部部件复核将在B3余下资产完成后统一进行；本目录预览未替换已采用F05-10页面。仍须游戏内核对底装落地、跨节点多部件遮挡、安装拆卸和真实状态提示。
