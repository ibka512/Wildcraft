# A13-C 接入建议与范围

本文件是已采用 B 方案的接入规范：进入0.22／退出0.28，尚未修改运行代码。

## 唯一建议参数变化

`src/client/java/dev/wildcraft/client/focus/FocusClient.java` 的有效专注状态切换分支目前统一调用 `SimpleSoundInstance.forUI(..., 1, 0.22F)`。按已采用 B 方案接入时，进入保留 0.22F，退出使用 0.28F；两个事件仍引用原 `WildcraftSounds.FOCUS_ENTER`／`FOCUS_EXIT`，不重编码 OGG、不新增 sound event 或字幕项。A方案0.22／0.22保留为历史对照；当前采用参数以B方案为准。

Minecraft 26.3 本机源显示 `forUI` 使用 `SoundSource.UI`、relative=true、attenuation=NONE。不要按旧版惯例写为 MASTER；证据及哈希见 `review/source-audit.json`。

## 保留当前触发规则

- 依据有效 view.active 的布尔边缘触发；相同 active 采样和持续按住不重复播放。
- 每次边缘先停止并释放上一个专注声音引用，随后在未暂停、未打开界面且角色存活时播放对应短音。
- 暂停／界面／死亡时仍更新布尔边缘状态，恢复后不补播错过的提示；重置／断开时停止残留。
- 图形滤镜开关不改变专注有效状态的声音规则；不要新增图形设置和音效状态耦合。
- 当前立即 stop 行为保留，不加新的过渡延迟、队列或音效冷却。

S01 总六声、同事件两声、单来源一声，优先级、去重及距离规则保持采用方案。专注为独立 UI 单声；原版音源不加入 S01 的六声预算。距离只衰减机械参照，不衰减专注音。

## 试听实现与生产边界

本页固定五秒安排、1秒进入／3秒退出，机械线性距离是 S01 审稿参照。参照统一 pitch=1，不随机改变两次对照；S01 生产规范中的安装／拆卸窄幅 pitch 变化仍以已采用规范为准。浏览器停止按钮对试听节点做 6ms 平滑，随后释放节点，不能照搬为游戏专注切换规则。

原版缓存声音只通过本地服务器白名单读取，路径来源见 `references/native-local-map.json`。页面和导出包不含原版 OGG，也不输出含原版音频的混音。未知路由、缺失或哈希变化的缓存拒绝读取，场景准备失败会明确提示，不能静默换成合成代理声。
