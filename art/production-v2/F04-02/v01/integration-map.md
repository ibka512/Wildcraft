## 图标遮罩

以空PNG为基底，每格由对应满PNG裁剪覆盖。矩形按[energy-regions.json](exports/energy-regions.json)原生坐标读取，文件顺序为上、中、下；处理顺序反转为下、中、上。满PNG保持高光与深红阴影，不重涂为单色。

设实际余量E，容量1000，i为自下而上编号0、1、2：格内份额 `clamp((3E − i×1000)/1000, 0, 1)`。显示宽度 `floor(w × clamp(3E − i×1000, 0, 1000) / 1000)`。先在原生像素取整，再以整数倍显示；不要先放大再取整，或开启线性插值。整格矩形高度不裁剪，宽度为零时不绘制。源与目标坐标相同。

E=0逐像素等于已采用空PNG；E=1000逐像素等于已采用满PNG。透明度与窗口外像素保持不变。按当前两端点设计，每列满窗像素与空窗像素全不同；32px只允许81处、16px只允许30处像素改变。

物理电池F04-01共用同一逻辑份额。其16px窗宽6列而HUD16px窗宽5列；不同取整结果是各原生设计的分辨率差异，不得拿某一图的窗口坐标直接覆盖另一图。3D窗口高度为连续份额，不受二维像素列宽限制。

## 数据来源与状态

`BatteryData.CAPACITY`为1000，schema=1，实际ItemStack保存余量。审稿控制器限制合法整数范围；不得因显示分档改写存储数据或创造额外能源等级。

`ChargerMenu.energy()`与单槽实际电池配合读取。根据槽内是否为有限电池判断有无电池；不能仅凭energy=0判断。状态0为无电池，1缺固定红石源，2充电中，3已满，4等待共享供电。正式状态从菜单同步读取；不能根据图标是否亮起推断供电状态。

| 场景 | 图标与数字 | 状态说明 |
| --- | --- | --- |
| 没有电池 | 隐藏图标，— / 1000 | 原status.0 |
| 放入空电池但无电源 | 空端点，0 / 1000 | 原status.1 |
| 500余量但无电源 | 半电份额，500 / 1000 | 原status.1 |
| 500余量充电中 | 半电份额，500 / 1000 | 原status.2 |
| 1000余量 | 满端点，1000 / 1000 | 原status.3；现逻辑优先判满，再判电源 |
| 500余量等待共享供电 | 半电份额，500 / 1000 | 原status.4 |
