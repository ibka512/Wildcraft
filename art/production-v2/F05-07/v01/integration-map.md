# F05-07 接入说明

本轮仅美术，未写入生产资源或修改Java/dev.14。显式网格与Blockbench free供编辑，不能直接当Minecraft方块模型JSON。Blender机体为隐藏独立参考，灯光/相机/地面只供审稿。

## 网格与坐标

模型单位1/16方块，原点[0,0,0]，+Z为轮轴外向。pivot=[0,0,4]，轴[0,0,1]；固定组9网格，轮体rotating58网格。六向基底、MachineNodes位置及整机yaw/roll保持现有规则。Blender用(x,z,y)/16，旋转父节点位于(0,.25,0)，子网格减本地Z4，Blender Y角为负age*.4。

深色胎芯与16块凸纹、钢圈、四辐条、铜嵌件、中心帽整体转动。固定座、两触点、四钉、轴承和轴不动。每个转动顶点径向长度≤4，因此任何相位不会扩大原半径；前缘保持4.32。真实孔洞没有背板封闭，后方轴座可能随视角遮住局部孔，是实际遮挡。

## 视觉状态

angle = active && !ghost ? ageInTicks*.4 : 0。active读取该节点位，不用整机working、enabled、电池存在或移动速度代替。预览与停转回到0相位，沿用现有行为；启动可能按实体age跳入相位，不新增累计转角或惯性。当前角度没有drive方向，后退也显示相同正转，不从客户端未同步输入猜方向。

原型仅旋转正面标记，新美术把该角度扩展至完整轮体；这是美术呈现适配，不更改服务端动力。Web页的20刻/秒播放是可暂停演示，默认静态，不是真实世界时间或能源消耗。

## 动力与接地边界

当前poweredWheels = body.onGround && drive!=0 ? wheelCount : 0；enabled与所有消费者完整能源支付后才设置wheel active。接地驱动每轮每世界刻1能量，推进沿整机本地Z按drive正负，不由安装轮轴决定。无乘客drive默认为1，有乘客W/S相同为0。整机最大台阶1方块需要enabled、working、active轮子且onGround。

未加载目的区块不提交，退还已付能源并清active。停机、无电、空中或无驱动输入会使轮子不工作；仅active=0不能区分原因，不增加伪缺电灯或轮子独立状态。

侧节点中心Y5.2模型单位、轮半径4，名义轮底Y1.2，即高于机体基底0.075方块。新稿保持现尺寸，没有扩大轮径、下移节点、移动机体或独立接触计算；接入后核对实际地形和阴影。如要调整轮径或接触姿态，需另列视觉尺寸变更，不混入此次模型制作。

## 图集、图标与ghost

64×64采用机械图集字节原样复用，UV0..16转像素×4，最近邻。recess/vent作深色胎面/槽纹，steel/copper作轮圈与嵌件；没有生产发光。图标32/16各独立三层Aseprite源，16作为常用原生尺寸、32另行适配，图标不携带真实能源信息。

透明预览颜色5DD7B7、alpha136/255，深度测试且不写深度；保持同尺度、0转角，已装配主体正常不透明。B3齐备后按F05-10全件复核遮挡。
