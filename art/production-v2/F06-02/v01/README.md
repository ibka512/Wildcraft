| 状态 | 界面表现 | 结果可见性 |
| --- | --- | --- |
| 0 材料就绪 | 中性方框、制造按钮可用 | 产出格为空 |
| 1 材料不足 | 琥珀断线符号、制造按钮禁用 | 显示实际材料数量，成本要求不变 |
| 2 制造中 | 双箭头、准确加载世界刻与进度条 | 不显示本批待提交结果 |

| 4 成品待取 | 勾号、完成满条与领取说明 | 显示实际产出格里的成品；取走后才能再次制造 |
