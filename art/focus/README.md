# 林克时间原创表现资源

P3.2 的表现源文件直接维护在 `src/client/resources/assets/wildcraft/shaders/post/`：

- `focus.fsh`：真实亮度去饱和、轻冷色、暗角、少量青绿色边缘和原创等距边缘轮廓。
- `focus_copy.fsh`：原版全屏顶点接口的复制输出；不从游戏资源复制片段源文件。
- `focus_pulse.fsh`：可选低精力极弱边缘提示，默认关闭。

`FocusEffectProvider` 按强度与开关生成 13 个后处理 JSON；只编辑源文件/生成器，再运行资源生成。强度 10%/15%/20% 为开发默认值。准星为 GUI 原生细线，保持视野中心清晰。

声音通过原版 SoundEvents 引用紫水晶音效，进入/退出使用不同音高和低音量；不包含游戏音频文件、任天堂素材或第三方着色器框架。FOV 开关只对原版世界相机结果追加 3% 缩放，不改玩家选项。

画面设置只保存在客户端 config，关闭画面不关闭技能和收费。实际 GPU 编译与截图见 P3.2 验证报告。
